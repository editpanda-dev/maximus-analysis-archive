# 공부 체류 POI 보조순위

- 대상: 공식 상권 786개
- 2025년 신호: 독서실 점포 수 15% + 카페 점포 수 15%
- 현재 POI 신호: 스터디카페 수 30% + 스타벅스 수 10% + 공공 학습시설 수 20%
- 접근성: 세 시간대 최소 접근률 10%
- POI 기준일: 2026-09-18

공공 학습시설 점수는 상권 내부 시설 밀도 80%와 상권 밖 400m 이내 시설 밀도 20%로 계산한다. 대상은 공공도서관·열람실·청년공간·대학 학습시설뿐이며, 스터디카페·대형카페는 카카오 장소 피처와 중복되지 않도록 공공시설 점수에서 제외한다.

## 사용 제한

스터디카페와 스타벅스, 공공 학습시설은 현재 스냅샷이다. 따라서 이 순위는 현재 추천 후보를 보강하기 위한 것이며, 2025년 매출 예측·검증에는 사용하지 않는다. 스타벅스는 대형·좌석형 카페의 제한적 프록시이므로, 향후 장소 상세정보·리뷰·혼잡도 검증으로 확장한다.
