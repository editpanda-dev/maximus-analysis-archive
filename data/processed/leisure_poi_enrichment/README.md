# 여가문화 POI 보조지수

- 대상: 25% 접근성 후보 공식 상권 786개
- 기준 순위: 2025년 4분기 여가문화 PATH-v0
- POI 기준일: 2026-09-16
- 점수: PATH-v0 백분위 85% + 여가 POI 보조지수 15%
- POI 보조지수: 상권·400m 문화시설 핵심 수 45% + 문화시설 다양성 30% + 영화관·공연장·전시공간·공원·스포츠시설 수 25%

## 사용 제한

POI 파일은 2026년 현재 스냅샷이며 `historical_2025_use_allowed=false`다. 따라서 이 산출물은 2025년 성능검증이나 과거 매출 예측에 사용하지 않는다. 최신 여가문화 후보를 설명하는 보조 순위로만 사용하며, PATH-v0 원본 순위는 변경하지 않는다. 운영 여부 관련 필드는 원천에서 비어 있어 점수에 사용하지 않았다.
