# appendix_discovery_tags (부록, 10/6 기준선 범위 밖)

Yang et al. (2026) 상권 분류 규칙을 응용해 만든 발견형 태그다. 식사·쇼핑 v1 점수에는 반영하지 않았다. 설명은 [`docs/appendix/appendix_discovery_tags_yang2026.md`](../../../docs/appendix/appendix_discovery_tags_yang2026.md)에 있다.

| 파일 | 내용 |
|---|---|
| `official_area_discovery_tags_786.csv` | 786행. 규모 등급, 기대 대비 결제 비율과 분기 커버리지, 리듬 비중과 z, 업종 엔트로피, 태그(`discovery_tags`), 유동 대비 결제 유형, v1 식사·쇼핑 순위 |
| `scale_tier_top5_food_shopping.csv` | 규모 등급(도시핵심·지역핵심·생활권)별 v1 식사·쇼핑 상위 5 |
| `discovery_tags_summary.json` | 태그별 상권 수와 안정성·교차 확인 요약 |

`footfall_quadrant`는 서울 열린데이터 길단위 인구(OpenAPI)로 계산한 유형이다. 원값은 저장소에 넣지 않았다.
