# 동대문구 출발 OD와 SERP-v1 (김건우, 2026-11-23 공유)

숨은 상권 A·B·C 작업(장한별 님 `숨은상권_ABC_계산방법`)의 한계 2·3번("상권 단위 유입 자료가 없다", "덜 알려짐을 매출로 대신했다")에 바로 쓸 수 있게 올립니다.

## 원천

서울 열린데이터광장 **서울 생활이동**(행정동 출발 → 행정동 도착, 시간대·연령별 이동 인구), 2025-12 ~ 2026-07, 8개월.
출발지는 동대문구 행정동만 쓰고, 도착 행정동을 서울 공식 상권(786곳)에 면적 비율로 나눠 붙였습니다.
행정동 단위 원본 행 파일(한 달 약 23MB)은 무거워서 올리지 않았습니다. 다시 만들려면 `scripts/members/gunwoo/workspace_2026_11/build_ddm_od_panel.py`를 씁니다.
3명 미만 칸은 서울시가 가려서 줍니다(`masked`). 그래서 작은 상권 값은 잡음이 큽니다.

`serendipity_ranking_v1_2.csv` 주요 열

- `act`, `exp`, `peer_ratio`: 실제 유입, 예상 유입, 실제 ÷ 예상. **1보다 작으면 거리·교통·상권 구조가 비슷한 다른 동 사람들보다 동대문구민이 덜 가는 곳**입니다.
- `under_months`: 8달 중 덜 간 달 수. 7달 이상인 곳만 추천 자격이 있습니다(한두 달 우연 배제).
- `inertia`: 늘 가던 곳 여부. 실제 유입 상위 20곳 + 예상보다 3배 넘게 몰리는 거점(왕십리형)입니다. **회기역에서 가깝다는 이유만으로는 빠지지 않습니다.**
- `path_pct`: 목적 점수 백분위, `transit_min`: 대중교통 분, `reason`: 사람이 읽는 설명 문장

## 한별 님 작업에 쓰는 법

1. **늘 가던 곳 목록**: "회기역에서 가까운 20곳 ∪ 매출 상위 20곳" 대신 `inertia == True`를 씁니다. 실제로 많이 가는 곳만 빠지니, 가깝지만 덜 가는 곳(예: 홍릉시장)이 다시 후보가 됩니다.
2. **B(덜 알려짐)**: 매출 하위 50% 대신 `peer_ratio`(낮을수록 동대문구민이 덜 감)를 씁니다. 매출은 "서울 전체에서 덜 팔림"이고, `peer_ratio`는 "우리 출발지 사람들이 덜 감"이라 과제 정의에 더 가깝습니다.
3. 둘 다 "모른다"를 직접 잰 값은 아닙니다. 알면서 안 가는 곳(멀다고 느낌, 취향)도 섞입니다. "알고 있었나"는 설문으로 확인해야 합니다.

## 상권 리뷰 집계표 (`../area_review_table/area_review_table_v1.csv`)

네이버 방문자 리뷰(식사 점포 2.8만 곳, 정제 리뷰 49.8만 건)를 상권 단위로 모은 표입니다. 열 설명은 `scripts/members/gunwoo/workspace_2026_11/build_area_review_table.py` 맨 위에 있습니다.

- `store_pop_top3_pct`: 상권 안 리뷰 수 상위 3개 가게 평균의 백분위입니다. **상권 이름 인지도가 아닙니다.** 경리단길·해방촌은 이름은 유명하지만 가게 리뷰는 중간으로 나옵니다.
- `share_<태그>`: 태그(느좋·감성 모임·데이트·가성비 혼밥·단체 회식 등) 해당 가게 비율. A(목적적합도)를 점포 수 대신 "그 목적으로 실제 쓰이는 가게 비율"로 바꿀 때 씁니다.
- `ddm_*`: 위 SERP-v1 값(식사, 전체 연령)을 같이 붙였습니다.
- 리뷰 원문과 작성자는 올리지 않았습니다(닉네임 포함). 필요하면 따로 요청해 주세요.
