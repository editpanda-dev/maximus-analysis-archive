# 어디가지 상권–점포 매핑

`area_store_20260630.zip`을 풀면 서비스 점포 카탈로그를 내보낸 UTF-8 CSV가 나옵니다. 기준일은 2026-06-30이며, 서울의 서비스 대상 상권 786개에 연결된 점포 219,859곳(상권–점포 연결 237,718건)을 담았습니다. Excel에서는 **데이터 → 텍스트/CSV에서**로 가져오고 `area_code`와 `place_id`는 텍스트로 지정하세요.

- 출처: [소상공인시장진흥공단 상가(상권)정보 서울 파일](https://www.data.go.kr/data/15083033/fileData.do). 점포 좌표를 서비스의 서울시 상권 경계 폴리곤 전체에 결합했습니다(경계 포함).
- 한 행은 `area_code`(상권 코드)와 `place_id`(점포 ID)의 조합입니다. 경계가 겹치면 같은 `place_id`가 여러 상권에 나타날 수 있습니다. 점포 단위 리뷰·임베딩은 `place_id`로, 상권 소속은 두 키의 조합으로 연결하세요.
- `area_name`, `place_name`, `address`는 상권명·점포명·주소입니다. `longitude`, `latitude`는 경도·위도입니다. `category_name`은 원천 업종 대·중·소분류 경로, `subcategory`는 서비스용 하위분류입니다.
- `purposes`는 방문 목적 태그의 JSON 배열입니다. 예: `food`(식사), `cafe`(카페), `shopping`(쇼핑), `study`(공부), `leisure`(여가). 태그가 없는 점포도 `[]`로 보존했습니다.
- 데이터는 중복 표시를 정리한 서비스 스냅샷이며, 현재 영업·폐업 여부나 목적 적합성을 현장에서 검수한 목록은 아닙니다.
