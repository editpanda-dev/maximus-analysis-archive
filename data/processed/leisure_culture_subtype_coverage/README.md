# 여가문화 하위목적 커버리지

이 폴더는 786개 접근 가능 공식 상권에 대해, 2026-09-16 현재 POI 피처를 네 개의 여가문화 하위목적으로 재조합한 감사 산출물이다.

- `official_area_leisure_culture_subtype_coverage_786.csv`: 상권별 시설 수·보유 여부·다양성
- `leisure_culture_subtype_coverage_summary.csv`: 하위목적별 집계와 커버리지

2025년 PATH-v0의 성능검증·과거 매출예측에 이 스냅샷을 사용하면 안 된다. 이 산출물은 최신 후보 설명과 이후 하위목적 점수식 설계의 입력이다.
