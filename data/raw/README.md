# 공개 원본 데이터

팀 내부 재현을 위해 분석에 직접 사용한 공개 원본을 보관한다. 각 파일의 최종 이용·재배포 조건은 해당 제공기관의 최신 약관을 따른다. 갱신 파일은 기존 파일을 덮어쓰지 말고 날짜를 파일명에 유지한다.

## 포함 범위

| 묶음 | 파일 | 사용처 |
|---|---|---|
| 서울시 상권분석서비스 | `seoul_commercial_*`, `commercial_area/*.zip` | 행정동·상권별 점포, 매출, 생활인구·직장·상주인구, 집객시설, 공식 상권 경계 |
| 서울 대중교통 공개정보 | `서울시버스노선별정류소정보_*.xlsx`, `seoul_station_master_*.csv`, `seoul_metro_timetable_*.csv` | 출발 정류장, 지하철역, 철도 시간표 |
| 교통 공급·경로 공개 파일 | `tpss_*.zip`, `kscc_*.zip` | 버스 구간 소요시간, 노선별 정류장·배차 정보 |

## 의도적으로 제외한 파일

- 서울시 빅데이터캠퍼스 B078/B079 표본과 전체 원자료: 폐쇄망·반출 정책 및 이용권한을 따르므로 이 저장소에 올리지 않는다.
- ODsay API 원응답 캐시: API 이용약관 및 호출 키 관리 범위에 속하므로 제외한다.
- 논문 PDF: 저작권상 원문 대신 문헌 정보·요약 문서만 보관한다.
- 중복 압축본: 같은 상권 CSV의 ZIP 사본은 저장소 용량 절약을 위해 제외한다.

## 갱신 원칙

1. 새 공개 파일의 공식 출처 URL·발급일·파일 해시를 이 문서 또는 커밋 메시지에 남긴다.
2. B078/B079처럼 반출 승인이 필요한 데이터는 승인된 집계 결과만 `data/processed/`에 추가한다.
3. API 키, `.env`, 개인 식별 가능 데이터는 커밋하지 않는다.
