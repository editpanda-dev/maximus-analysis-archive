## 한 줄 요약

동대문구의 버스정류장과 지하철역 334개를 출발지로 설정하고, 시간대별 정적 대중교통 그래프에서 30분 이내 도달 가능한 정류장을 계산했다. 이 결과를 서울시 공식 상권 폴리곤 1,650개와 직접 결합해 접근성 탐색 후보 786개를 만들었고, 해당 후보에 대해 목적별 PATH-v0 기준선도 재산출했다.

## 완료한 작업

### 1 출발지 정의

- 동대문구 버스정류장 325개를 구축했다. 서울시 버스정류소 위치정보에서 동대문구 ARS ID 대역을 기준으로 선별했다.
- 동대문구 안 지하철역 9개를 별도 좌표 확인해 추가했다.
- 최종 출발지 파일은 `data/external/odsay_origins.csv`이며 총 334개다.

### 2 30분 대중교통 도달권 계산

- 버스정류장과 지하철역을 노드, 운행구간과 도보 환승을 엣지로 하는 방향성 그래프를 만들었다.
- 이동비용에는 출발 도보, 최초 대기, 운행시간, 환승 대기와 추가시간, 환승 도보를 포함했다.
- 다익스트라 탐색으로 각 출발지에서 30분 이내인 정류장·역을 계산했다.
- 오전 8시, 오후 2시, 오후 7시 세 시간대를 따로 계산했다.
- 생성 결과는 `data/processed/local_transit_30min/h08`, `h14`, `h19`에 있다.

### 3 행정동과 공식 상권 후보 생성

- 도달 정류장을 행정동 경계와 결합해 세 시간대 공통 접근 생활권을 확인했다.
- 실제 추천·분석 단위는 행정동이 아니라 서울시 상권분석서비스의 공식 상권 폴리곤으로 설정했다. 공식 단위는 골목상권, 발달상권, 전통시장, 관광특구다.
- 상권 폴리곤 경계 400m 이내에 도달 정류장이 있는 출발지 비율을 상권 접근률로 계산했다.
- 세 시간대 중 최저 접근률이 25% 이상인 상권을 접근성 탐색 후보로 남겼다.

## 확정된 현재 수치

| 기준 | 공식 상권 수 |
|---|---:|
| 전체 공식 상권 폴리곤 | 1,650개 |
| 세 시간대 공통 25% 이상 | 786개 |
| 세 시간대 공통 50% 이상 | 634개 |
| 세 시간대 공통 80% 이상 | 394개 |
| 동대문구 경계와 겹치는 25% 후보 | 84개 |

25%는 334개 출발지 중 최소 약 84개 출발지에서 세 시간대 모두 접근 가능하다는 뜻이다. 786개는 모든 사용자에게 보여줄 최종 추천 목록이 아니라, 교통 접근성만으로 제외하지 않은 넓은 탐색 풀이다. 실제 추천에서는 사용자의 선택 출발지와 시간대에서 다시 후보를 제한한다.

## 중요 정정 사항

이전 문서와 덱에 있던 `26개 공식 상권 후보`는 사용하면 안 된다.

원인은 이동 결과·상권 통계에 쓰는 행정동 코드와 행정동 경계 GeoJSON의 공간 코드가 서로 다른 체계였는데, 기존 코드가 이를 같은 코드처럼 비교한 것이다. 예를 들어 회기동은 통계 코드가 `1123071000`, 경계 공간 코드는 `11060710`이다. 앞자리 일부만 잘라도 서로 일치하지 않는다.

수정 후에는 행정동 코드로 상권을 사전 제외하지 않고, 도달 정류장 좌표와 공식 상권 폴리곤을 직접 공간 결합한다. 현재 스크립트는 이 방식으로 수정돼 있다.

## 목적별 PATH-v0 기준선

786개 상권에 2025년 분기별 점포·매출 피처를 붙여 목적별 규칙 기반 점수를 다시 계산했다.

- 목적: 식사, 카페, 공부, 쇼핑, 여가문화의 5개
- 공급점수: 목적 관련 점포 수 65% + 상권 내 목적 업종 비중 35%
- 소비점수: 목적 업종 매출 50% + 목적 매출 비중 25% + 적합 시간대 매출 비중 25%
- PATH-v0 점수: 현재 분기 공급점수 70% + 직전 분기 소비점수 30%

현재 시설 데이터는 2026년 2분기 자료여서 2025년 순위에 넣으면 미래정보 누출이 발생한다. 따라서 이번 PATH-v0에는 시설 변수를 넣지 않았다. 특히 공부와 문화 추천은 이후 동시점 POI·시설 자료를 확보해 보완해야 한다.

이 결과는 학습된 추천모형이 아니라 투명한 기준선이다. 가중치 65:35와 70:30은 팀이 정한 초기 규칙이며, B078 전체 원본을 확보한 뒤 실제 목적지 선택을 정답으로 사용해 학습모형과 비교해야 한다.

## 유동인구 매출 괴리 EDA

행정동 단위 EDA에서는 2025년 4개 분기, 접근성이 안정적인 151개 행정동을 분석했다.

- 유동인구와 매출의 Spearman 상관계수: 0.555
- 유동인구·점포 수 기반 비선형 기대매출 모형의 분기 홀드아웃 로그매출 R2: 0.895
- 같은 입력변수의 선형 Ridge 기준선 R2: 0.792
- 151개 중 13개 행정동에서 4개 분기 중 3개 이상 기대매출 괴리가 반복됨
  - 기대보다 높은 후보 5개
  - 기대보다 낮은 후보 8개

13개는 상권 유형 확정 결과가 아니라 후속 조사 후보다. 2023년부터 2025년까지 기간을 확장하면 같은 괴리 방향이 3년 내내 유지된 곳은 4개뿐이다. 기대매출은 쇼핑·식사 추천의 직접 점수가 아니라, 유동 규모 대비 소비가 특이한 지역을 찾는 진단 변수로만 사용한다.
