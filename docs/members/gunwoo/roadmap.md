# 추후 연구 방향

정리: 2026-11-04 · 근거: [`research_log.md`](research_log.md) 1.8·2.7·3.1·7·8장, [`service_ideas.md`](service_ideas.md)

지금까지 만든 것은 "점수를 매기는 틀"이다. 틀이 맞는지 확인할 **정답 라벨**과, 점포 단계를 채울 **신호**가 비어 있다. 그래서 순서는 ① 라벨을 먼저 만들고 ② 이미 만든 것의 실제 영향을 확인한 뒤 ③ 라벨로 검증하면서 기능을 늘리는 쪽으로 잡았다.
