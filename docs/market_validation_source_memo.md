## 경쟁구조

- 네이버지도: POI, 리뷰, 검색, 경로, 예약의 범용성이 강점. 사용자가 이미 장소나 키워드를 아는 검색 과업에 강함.
- 카카오맵: 경로 탐색과 카카오 생태계 공유가 강점. 시간예산을 먼저 적용한 목적별 상권 비교는 핵심 전면 기능이 아님.
- 데이트팝: 자체 큐레이션, 할인권, 제휴 매장, 구독으로 콘텐츠와 거래 전환이 강함. 연인·데이트 중심이며 제휴/편집 콘텐츠 의존성이 큼.
- 대한민국 구석구석: 공신력 있는 관광·축제 콘텐츠가 강점. 일상 생활권의 30분 이동 제약과 상권 순위화가 핵심은 아님.
- 캐치테이블: 식당 예약·웨이팅과 방문 전환이 강점. 식음료 외 목적과 상권 단위 복합 비교 범위가 제한됨.

차별점은 지도나 예약을 대체하는 것이 아니라, 목적지가 정해지기 전 단계에서 `시간 제약 → 도달 가능한 상권 → 목적별 순위 → 근거 설명`을 제공하고 이후 지도·예약 파트너로 연결하는 것이다.

## TAM–SAM–SOM–LAM

초기 고객을 대학생으로 한정하여 포함관계를 유지한다.

- TAM: 전국 일반대·전문대 재학생 2,328,667명.
- SAM: 수도권 일반대·전문대 재학생 1,009,971명.
- SOM: 서울 일반대·전문대 재학생 506,510명의 5%를 3년 내 활성 이용자로 확보한다는 내부 목표 = 25,326명. 5%는 실적이 아닌 검증할 가정이다.
- LAM: 한국외대 서울캠퍼스 재학생 11,968명의 25%를 첫 12개월 내 도달 가능한 사용자로 설정 = 2,992명. 25%는 교내 채널을 활용한 내부 목표이며 실적이 아니다.

수익가치 환산은 검증 전 가정인 연간 혼합 ARPU 12,000원을 사용한다. 이는 무료 이용자 광고·제휴 수익과 일부 유료 이용자를 합친 평균 목표치이며 인터뷰·광고 테스트·예약 전환 실험으로 검증해야 한다.

- TAM 가치: 2,328,667 × 12,000원 = 27,944,004,000원/년.
- SAM 가치: 1,009,971 × 12,000원 = 12,119,652,000원/년.
- SOM 가치: 25,326 × 12,000원 = 303,912,000원/년.
- LAM 가치: 2,992 × 12,000원 = 35,904,000원/년.

## BM 가설

1. B2C 무료 핵심 추천 + 프리미엄 구독: 광고 제거, 다목적 코스, 저장·공유, 날씨/혼잡 조건. 가격과 유료전환율은 실험 전 미확인.
2. 예약·티켓·클래스 제휴 중개: 실제 예약 또는 구매가 발생했을 때만 수수료. 파트너 조건은 미확정.
3. 지역 상점의 스폰서드 카드: 추천모형과 광고 슬롯을 분리하고 광고임을 명확히 표시. 자연순위를 금전으로 왜곡하지 않는다.
4. B2B/B2G 분석: 시간대·목적별 집계 유입 대시보드 또는 리포트. 제한 데이터의 이용·반출 조건을 준수하며 개인 추적을 하지 않는다.

초기 수익 우선순위는 제휴 중개와 명확히 표시된 광고이며, 구독과 B2B는 반복사용·지불의사 검증 뒤 도입한다.

## 실행 로드맵

- 0–4주: 30명 문제 인터뷰, MVP 과업 테스트 20명, 주요 실패 이유 기록. 회기/외대앞 출발·30분 이내·6개 목적의 공개데이터 규칙 기반 데모 안정화.
- 5–8주: 최소 300명 베타, 추천 클릭률·조건 입력 완료율·추천 이유 이해도·7일 재방문율 측정. 거리순/인기순과 목적별 규칙 비교.
- 9–12주: 교내·인근 상점 10곳 제휴 인터뷰, 예약/쿠폰 클릭 실험, 스폰서드 카드의 광고 표기 테스트. 데이터 접근 승인 여부에 따라 통계모형 검증 착수.
- 4–6개월: 서울 동부 대학가 3개 권역으로 확대, 1,000 MAU 목표, 추천 후 지도 열기/저장/공유 전환 측정. LightGBM/CatBoost는 훈련·검증 데이터가 확보될 때만 사용하고 SHAP으로 설명한다.
- 7–12개월: LAM 2,992 활성 이용자 목표를 검증. 제휴 중개 매출과 광고 파일럿을 비교하고, 월별 단위경제성이 확인될 때만 구독을 시험한다.
