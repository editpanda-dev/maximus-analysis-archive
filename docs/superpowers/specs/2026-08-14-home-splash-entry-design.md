# 홈·스플래시 진입 흐름 설계

## 목표

앱을 처음 열 때 브랜드 스플래시와 간결한 홈 화면을 보여주고, 사용자가 명시적으로 추천 조건 설정 화면으로 진입하게 한다.

## 사용자 흐름

1. 앱 실행 시 로고·서비스명 `어디가지`를 표시하는 스플래시를 1초간 보여준다.
2. 스플래시는 자동으로 홈 화면으로 전환한다. 사용자가 조작해 건너뛰는 버튼은 제공하지 않는다.
3. 홈 화면은 서비스 한 줄 설명과 `추천 시작하기` 단일 CTA를 보여준다.
4. CTA를 누르면 기존 출발지·시간·목적 조건 설정 화면으로 이동한다.
5. 조건 설정 화면에서 뒤로가기를 누르면 홈 화면으로 돌아간다. 입력 중인 조건은 유지하지 않고, 다음 시작 시 기본값으로 새로 연다.

## 화면과 상태 경계

- `LaunchView`: 스플래시 전용. 네트워크·위치·추천 API를 호출하지 않는다.
- `HomeView`: 진입 안내와 CTA만 제공한다. 추천 상태를 소유하지 않는다.
- `ContentView`: 기존 조건 설정·동네 카드·점포 상세 흐름을 유지한다. 홈에서 새 인스턴스로 열기 때문에 이전 추천 결과가 남지 않는다.
- 앱 루트는 `LaunchView → HomeView → ContentView` 전환 상태만 소유한다.

## 오류와 접근성

- 스플래시와 홈은 오프라인에서도 표시된다.
- 동네 추천 API 오류는 기존 조건 설정 화면의 오류 안내를 그대로 사용한다.
- CTA와 뒤로가기에는 접근성 레이블을 제공한다.

## 검증 기준

- 스플래시 타이머 완료 시 홈으로 전환되는 단위 테스트.
- 홈 CTA가 조건 설정 화면을 열고, 설정 화면의 뒤로가기가 홈으로 돌아오는 UI/상태 테스트.
- 기존 동네 추천 XCTest가 계속 통과.
- iPhone 17 Pro 시뮬레이터에서 앱 실행 시 스플래시, 홈, 조건 설정 화면을 순서대로 확인.
