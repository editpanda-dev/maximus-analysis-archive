# 행정동 우선 추천 설계

## 목표

사용자가 출발지·목적·이동 제한시간을 선택하면 개별 점포 대신 접근 가능한 행정동을 먼저 추천한다. 사용자가 행정동을 선택하면 그 동네 안의 구체적인 점포와 카카오 대중교통 경로를 확인한다.

## 범위와 원칙

- 추천 단위는 행정동이다. 화면에는 `모현읍`, `죽전동`처럼 행정동 명칭만 표시한다.
- 출발지는 대한민국 지원 지역의 좌표여야 한다.
- 후보는 카카오 장소 검색 결과와 카카오 대중교통 경로가 모두 있는 실제 점포만 사용한다.
- 제한시간을 초과하거나 대중교통 경로가 없는 점포는 제외한다.
- fixture, 다른 이동수단, 임의의 동네·점포 데이터로 대체하지 않는다.
- 카카오 REST 키는 서버 환경변수에만 둔다. iOS는 백엔드 API만 호출한다.

## 사용자 흐름

1. 사용자가 출발지, 목적, 20·30·40·60분 제한시간을 선택하고 추천을 요청한다.
2. 서버는 목적별 카카오 장소 후보를 검색하고, 각 후보의 카카오 대중교통 경로를 구한다.
3. 제한시간 이내인 점포를 주소의 행정동으로 묶어 행정동 후보를 만든다.
4. iOS는 최대 5개 행정동 카드를 보여준다. 각 카드는 행정동명, 가장 빠른 예상 이동시간, 해당 목적의 점포 수를 표시한다.
5. 사용자가 행정동 카드를 누르면 해당 행정동의 점포 목록을 표시한다.
6. 점포 카드를 누르면 기존 상세 화면에서 주소·예상 소요시간·거리·대중교통 단계를 보여준다.

## 추천·정렬 규칙

### 점포 후보

- 카카오 키워드 검색은 현재 목적 매핑을 그대로 사용한다(예: `cafe` → `카페`).
- 검색 반경은 현재와 같이 출발지 기준 10km, 최대 15개다.
- 점포별 가장 빠른 카카오 대중교통 경로의 총 소요시간을 사용한다.
- 총 소요시간이 사용자가 고른 제한시간 이하인 점포만 적격이다.

### 행정동 후보

- 각 적격 점포의 도로명 주소가 있으면 그 주소를, 없으면 지번 주소를 사용해 행정동을 추출한다.
- 주소에서 신뢰할 수 있는 행정동을 추출할 수 없는 점포는 행정동 추천에서 제외한다. 잘못된 동네로 추정하지 않는다.
- 같은 행정동의 점포는 하나의 후보로 묶는다.
- 행정동 정렬은 다음 순서다.
  1. 소속 점포 중 최소 예상 이동시간 오름차순
  2. 소속 적격 점포 수 내림차순
  3. 가장 빠른 점포의 거리 오름차순
  4. 행정동명 가나다순
- 최대 5개 행정동만 반환한다.

### 점포 상세 목록

- 선택 행정동의 적격 점포만 반환한다.
- 점포 정렬은 예상 이동시간, 거리, 장소명 순이다.
- 초기 버전은 서버가 행정동별 상위 점포를 응답에 포함해 iOS의 재요청 없이 상세 목록을 연다. 이로써 동네 카드와 점포 목록의 기준 시점과 결과가 항상 일치한다.

## API 및 데이터 경계

- 기존 `POST /v1/live-recommendations`를 행정동 우선 응답으로 교체하지 않는다. 새 계약 `POST /v1/live-district-recommendations`를 추가한다.
- 요청은 기존 라이브 요청과 동일하다: 출발지명·위도·경도·목적·제한시간.
- 응답은 공급자(`kakao`), 조회시각, 적격 점포 수, 행정동 후보 목록, `fixture: false`, 제한사항을 포함한다.
- 행정동 후보는 `district_name`, `fastest_travel_time_seconds`, `place_count`, `places`를 포함한다.
- `places`는 현재의 장소명·주소·좌표·소요시간·거리·경로 단계 모델을 재사용한다.
- iOS의 기존 직접 점포 추천 API 클라이언트는 호환성을 위해 유지하되, 기본 추천 화면은 새 행정동 API를 사용한다.

## 오류 처리와 UX

- 해외·지원 밖 출발지는 서버 호출 전에 기존과 같은 대한민국 출발지 안내를 표시한다.
- 카카오 장소/경로 공급자 오류는 기존의 안전한 오류 메시지로 처리하며 키·원문 오류를 노출하지 않는다.
- 적격 점포가 없으면 “선택한 조건 안에서 갈 수 있는 동네를 찾지 못했어요” 상태를 표시한다.
- 행정동을 선택한 뒤 뒤로 가면 출발지·목적·시간 및 행정동 후보 목록을 보존한다.
- 개인정보 문구는 선택 좌표가 추천 API와 카카오맵 서비스의 장소·대중교통 경로 조회에 사용됨을 유지한다.

## 검증 기준

- 서버 단위 테스트: 행정동 추출, 동일 행정동 그룹화, 정렬 타이브레이커, 불명확 주소 제외, 시간 초과/무경로 제외, 최대 5개 동네 제한.
- HTTP 테스트: 새 엔드포인트 성공·대한민국 밖 좌표 422·공급자 오류 안전 매핑.
- iOS 테스트: 새 요청 snake_case 인코딩, 동네 응답 매핑, 카드 선택 시 해당 점포만 표시, 빈 결과·오류·뒤로가기 상태.
- 통합 테스트: 모현 한국외대에서 30분 카페 요청 시 카카오 결과만으로 행정동 카드와 그 안의 점포 목록을 표시한다.

## 비목표

- 평점·리뷰·영업 여부·혼잡도·요금·실시간 도착예정 기반 순위화
- 상권 단위, 역세권 단위, 개인화 또는 ML 랭킹
- 행정동 후보 클릭 후 추가 카카오 호출
