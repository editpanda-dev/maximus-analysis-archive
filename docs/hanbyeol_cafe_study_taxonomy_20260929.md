# 카페·공부 하위분류 및 점수 설계안

작성: 장한별 담당 범위 · 2026-09-29 · 상태: **9월 29일 설계 제출본** (786개 v1 점수 산출 전)

**추가 피드백 반영:** [보행거리·중복·민감도 후속 진단](hanbyeol_cafe_study_followup_20260929.md)이 이 문서의 직선거리 400m, 인접시설 0.25, S3a+S3b 합산, 면적 0.02km² 가정을 검증한다. 아래 해당 수식은 **원래 제출 당시 초안**으로 남겨 두었으며, 최종 점수 확정식으로 사용하지 않는다.

**2026-10-03 식사 taxonomy 대조:** 김건우님 `meal_shopping_taxonomy_20260930.md` 제공본도 공식 `CS100005` 제과점을 식사에서 제외해 카페 C2로 분류하고, `CS100009` 호프·간이주점을 여가로 분류한다. [1~3단계 교차 검수](hanbyeol_steps_1_3_review_20261003.md)에 입력량 이동과 미반영 상태를 기록했다. 식사·카페·여가 점수를 같은 버전으로 재생성하기 전에는 혼합 목적 순위를 최종본으로 간주하지 않는다.

## 1. 적용 범위와 판정 원칙

- 행 단위는 서울시 공식 상권 `area_code` 1개다. 동대문구의 334개 승차 지점, 세 출발 시간대(08·14·19시), 대중교통 30분 조건을 적용해 세 시간대의 최소 접근률이 25% 이상인 **786개 상권**을 유지한다. 50%·80% 접근률은 설명용 tier다.
- 대분류 `카페`는 **음료·디저트를 사거나 즐길 장소**, 대분류 `공부`는 **실제로 머물며 학습할 공간**이다. 업종 수는 장소의 공급 추정치이고, 카드 추정매출은 해당 업종 소비의 관측 대리변수다. 둘 모두 좌석, 공부 허용, 개별 방문 목적을 증명하지 않는다.
- `확인`은 원천의 해당 속성에 대한 근거가 있다는 뜻으로 한정한다. 등재·지도 검색·영업정보 스냅샷은 **오늘 영업 중**이나 **현재 좌석 이용 가능**을 보증하지 않는다. 확인 근거가 없으면 `unknown`이며 자동으로 `false`로 바꾸지 않는다.
- **기존 PATH-v0의 2025년 점수와 현재 2026년 POI 보조점수는 유지·구분한다.** 아래 v1 설계 가중치는 제안값이며 2025년 성능 검증에 2026년 POI를 넣지 않는다. 관광특구 제외는 팀 제안 단계이므로 786행을 임의로 줄이지 않는다. 별도 `recommendation_eligible` 후보 플래그로 논의한다.

## 2. 하위분류 taxonomy

상위 목적별 **기본 시설 유형은 중복 없이 한 번만 집계**한다. `체류 가능`은 별도의 증거 태그로, 기본 유형과 교차할 수 있으나 합산할 때 이중 가산하지 않는다.

| 코드 / 하위분류 | 포함 규칙 | 제외·보류 규칙 | 점수에 쓸 신호 |
|---|---|---|---|
| `C1` 음료 카페 | 서울시 상권분석서비스 `CS100010` (`커피-음료`) 점포·매출. 장소 POI에서는 실제 카페 업종으로 확인된 곳 | 음료 판매 여부가 확인되지 않은 식당·주점, `스터디카페`를 일반 커피 매장으로 중복 계산하지 않음 | 점포 규모·특화도·매출 및 11–17시 비중 |
| `C2` 베이커리·디저트 | 공식 `CS100005` (`제과점`) 업종. 메뉴 POI는 빵·디저트 판매가 확인된 장소만 | 제과점 전체를 좌석 있는 카페로 간주하지 않음; 식사 대분류와 동시에 중복 산입 금지 | 제과점 점포·추정매출; 착석 가능 여부는 별도 |
| `C_stay` 착석·체류 확인 카페 (교차 태그) | 영업/공간 설명에서 좌석과 체류 이용을 확인한 C1/C2 장소. 층면적·Wi-Fi는 후보 단서로 기록 | 스타벅스라는 브랜드, 대형 면적, Wi-Fi만으로 **공부 가능** 또는 **장시간 체류 확인** 판정하지 않음 | 확인된 장소 수; 좌석·이용시간·구매 조건은 확인 시 별도 |

| `S1` 공공도서관 학습공간 | 도서관 원천의 공개 접근과 **열람좌석 수 > 0**을 확인한 시설 | 좌석 0·결측, 학교 소속 출입 제한, 폐관 확인 시설은 확인형 학습점수에서 제외. 원천에 등재되었더라도 운영은 별도 확인 | 적격 POI 내부·400m 수, 좌석 수는 품질 참고 |
| `S2` 공공 청년·열람공간 | 공식 청년공간 또는 열람실 중 일반 이용자 접근과 실제 학습 용도가 각각 확인된 시설 | 청년 대상이라는 사실만으로 모든 사용자에게 개방된 공부방으로 간주하지 않음; 유료·회원제·캠퍼스 열람실은 검토 대상으로 분리 | 조건 확인 후 적격 POI 수. 나이·예약 제한 기록 |
| `S3` 유료 전용 학습공간 | 스터디카페 및 독서실로 식별되는 공간. 카카오 `study_cafe`와 공식 `CS200038` (`독서실`) 점포는 **서로 다른 원천 유형**으로 기록 | 학원, 서점, 문구점, 완구점, 캠퍼스 주소. 동일 시설이 OSM·카카오에 있으면 하나의 장소만 POI 점수에 사용 | 스터디카페 POI 수 + 독서실 업종 공급. 가격·좌석은 검증 전 미사용 |
| `S4` 카페 학습공간 | `C_stay` 중 학습 목적 이용 허용을 **추가로 확인**한 장소 | 일반 카페 점포 수, 스타벅스 검색 결과, 대형카페 면적·Wi-Fi만으로 학습 적합 판정 금지 | 검증된 학습 카페 POI 수. 구매 의무는 표시 |
| `S_review` 접근 제한·근거 부족 후보 | 대학도서관, 이용 조건 불명 열람실, 좌석/용도 불명 공공시설과 카페 | 점수 대상에 자동 편입하지 않음; 누락으로 삭제하지 않고 검토 목록 유지 | 점수 외 후보·커버리지 열 |

**정확한 현재 범위:** `study_public_facility_poi.csv`는 268행이다(공공도서관 205, 열람실 14, 청년공간 17, 대학시설 9, 스터디카페 10, 대형카페 13). 기존 `public_feature_included=1`은 **236행**이지만 이 중 열람실 14행은 `public_access_verified=0`, 도서관 5행과 청년공간 1행은 `study_access_verified=0`이다. 따라서 236은 **기존 점수 포함 플래그 수**이지 위 S1·S2의 엄격한 확인형 총수가 아니다. 기존 공공 피처에는 대학시설 9행과 카페류 23행이 들어가지 않는다. 2026-09-18 카카오 스냅샷 1,266행은 `study_cafe` 852, `starbucks` 414이며 서울 후보 상권 내부 시설 수나 학습 가능 시설 수와 같지 않다.

## 4. 공간 집계·중복·상태

1. 공식 폴리곤과 WGS84 POI를 동일한 미터 좌표계(기존 공공시설 구현은 **EPSG:5186**)로 변환한다. v1에서 `inside`는 경계 포함(`covers`, 거리 0m)으로, `buffer400`은 폴리곤 경계에서 **400m 이하**로 정의하고 내부를 포함한다. `nearby_only = buffer400 − inside`. 정확히 경계·400m인 점은 포함한다. 기존 공공시설 코드의 `within`은 경계점을 내부에서 제외하므로 v1 생성 시 수정하고 경계 사례를 검사한다. 포인트의 직선거리 400m이지 실제 보행거리나 30분 교통 도착 후 이동시간이 아니다.
2. 동일 `place_id`는 한 상권·하위분류에서 한 번만 센다. OSM·Kakao처럼 ID가 다르면 정규화 시설명+주소/건물+좌표(우선 30m 이내)로 **후보 쌍**을 만들고 이름·동일 건물·업종을 확인해 대표 ID를 수동 확정한다. 30m라는 거리만으로 자동 병합하지 않는다. 서로 다른 상권의 버퍼에 한 시설이 반복되는 것은 허용한다.
3. `public_access_verified`, `study_access_verified`, `operation_status`, `source_reference_date`, `mandatory_purchase`, 좌표 유효성은 **서로 다른 축**으로 보존한다. 공공 원천의 `public_feature_included`는 이전 집계 재현용이며 엄격한 S1/S2 적격 판정 대신 쓰지 않는다. 폐업·영업종료가 명시되면 제외한다. 운영 미확인은 `operation_unknown=1`로 표시하고 실시간 영업 점수는 생성하지 않는다.
4. `C_stay`, `S4`의 **확인된 시설만** 체류형 점수에 반영한다. 확인되지 않은 카페는 C1/C2의 일반 공급·매출에는 남긴다. 2025년 업종 점포수에는 위치좌표가 없어 400m 점포수를 만들 수 없다. B·C는 상권 코드 내부 집계로만 사용하고, 400m는 좌표 있는 POI에만 적용한다.
5. 관광특구를 향후 후보 표시에서 제외하더라도 QA 표와 원천 피처는 786개 전부 남기며, 분모·백분위 모집단을 변경할 경우 점수 버전과 상위 순위의 모집단을 명시한다.

## 5. 공급·소비 변수와 산정식 초안

### 공통 변환 및 결측

- POI 하위유형 `t`, 상권 `a`: `N_t(a)=inside_t(a)+0.25×nearby_only_t(a)`를 기본 유효 수로 제안한다. 내부와 주변을 별도 열로 보존한다. 0.25는 검증 전 가중치이며 0/0.25/0.5 민감도 분석을 한다. **내부 포함 `buffer400`을 `inside`에 다시 더하지 않는다.**
- 면적 보정 밀도 `D_t=N_t/max(area_km2, 0.02)`를 제안하고, 0.02km² 바닥값·상위 99백분위 절단을 사용한다. 카페 공식 점포수는 상권 내부 점포 밀도와 상권 전체 대비 업종비중을 함께 보며, 작은 면적의 과도한 밀도값은 점검한다. 이 상수는 재산출 전 데이터 분포와 민감도 검토 대상이다.
- `P(x)`: 786개 **동일한 대상 상권·동일 기간·동일 하위유형** 내 `log1p(max(x,0))`의 평균순위 백분위 ×100. 공급·소비 규모 항목은 관측된 0에 **0점**, 양수에만 백분위를 계산한다. 비중 항목도 관측 0은 0점이다. 접근률은 786개 전체 백분위. 모든 상권에서 값이 동일하면 식별력이 없으므로 그 항목은 0점으로 두고 `noninformative=1` 표시한다. 순위 동점은 `area_code` 오름차순으로 정렬한다.
- 점포가 없음을 **원천 전수의 관측 0**으로 확인했을 때만 `0`. 업종별 매출행이 누락된 경우 `sales_observed=0`, 소비점수는 **NA**, 0이나 평균 추정값으로 대체하지 않는다. 분모 0의 매출비중도 NA다. 소비 가중치 재배분 여부와 커버리지를 함께 기록한다. POI 수집이 불완전하면 `observed_count=0`은 **미관측**으로 설명하며 지역에 실제 시설이 없다는 단정은 하지 않는다.

### 공부

`study_cafe`(유료 전용), `verified_cafe_study`(카페 학습), `verified_public`(엄격한 S1/S2), `study_room_supply`(공식 독서실 및 중복 제거된 공간 후보)는 독립 집계한다. 같은 시설은 하나의 기본 유형으로만 들어간다.

| 구성 | 제안 점수 / 총 가중치 | 자료상 확인 수준 |
|---|---|---|
| 유료 스터디카페 `S3a` | `P(N_study_cafe)` × **30%** | 카카오 검색 POI는 이름/업종 확인 후보. 폐업·같은 장소 중복 검토 필요 |
| 카페 학습공간 `S4` | `P(N_verified_cafe_study)` × **25%** | 좌석과 학습 허용의 근거가 있는 장소만. 기존 스타벅스 10% + 일반 카페 공급 15%의 **프록시를 그대로 확인값으로 승격하지 않음** |
| 공공 학습시설 `S1+S2` | `P(N_verified_public)` × **20%** | 공개 접근·학습 공간 확인 동시 충족. 기존 236개 `study_public_*`는 그대로 대체하지 않고 재집계 필요 |
| 기타 학습 공급 `S3b` | `P(공식 독서실 점포밀도)` × **15%** | 업종 공급 추정. 카카오 스터디카페 POI와 동일 시설 이중 집계 여부 점검; 독서실 이용료·회원제는 근거 별도 |
| 접근성 | `P(minimum_period_ratio)` × **10%** | 3시간대 최저 도달률. 실제 시설 문 앞 접근성은 아님 |

`Study_v1 = 0.30 S3a + 0.25 S4 + 0.20(S1+S2) + 0.15 S3b + 0.10 A`는 다섯 입력이 정의·수집·QA된 뒤 산출한다. 현재 S4의 전수 근거가 없으므로 **확정 v1 공부점수라고 주장할 수 없다.** 중간 표에는 기존 `study_stay_current_score`를 `legacy_proxy_score`로만 보존하고, 확인형 S4가 비어 있는 경우 `v1_status=incomplete_stay_evidence`와 구성 점수만 공개한다. 0으로 대입해 순위를 만들거나 나머지 가중치를 몰래 재배분하지 않는다. 공부의 소비 신호는 매출이 공부 방문을 식별하지 못하므로 `not_applicable`; 공식 독서실 매출이 없는 상황을 0으로 처리하지 않는다.

공식 독서실 **집계 점포 수**와 스터디카페 **개별 POI 수**는 실제 동일 사업장을 일부 공유할 수 있다. 전자에는 개별 점포 ID·좌표가 없어 정확한 장소 간 중복 제거가 불가능하다. 두 신호는 서로 다른 공급 프록시로 표시하고, 두 수를 더해 “고유 학습시설 총수”라고 제시하지 않는다. 원점포 데이터가 확보되면 교차 매칭을 실시한다.
