# 1차 EDA 계획

## 0. 데이터 감사

- 파일별 기간, 행 수, 메모리, 인코딩, dtype
- 논리 키 중복과 누락
- 코드별 빈도와 코드북 불일치
- 이동량·금액의 0, 결측, 마스킹, 이상치
- 지역 매칭률과 JOIN 전후 보존율

## 1. 생활이동

- 목적별 이동시간·거리 분포
- 연령대 × 목적별 유입량
- 평일/주말 및 시간대별 목적지 유입
- 출발·도착 행정동별 총량과 OD 집중도
- 이동시간 구간별 유입 감소 패턴

## 2. 카드소비

- 업종별 이용건수·금액 분포
- 고객지역→소비지역 흐름
- 목적지별 외부 소비 비중
- 장거리/타지역 소비 비중의 시계열

## 3. 상권 특성

- 음식·카페·소매·문화 점포 밀도
- 업종 다양성(Shannon entropy)과 집중도(HHI)
- 프랜차이즈 비율, 개폐업률, 매출, 인구, 집객시설
- 변수 간 상관, 왜도, 다중공선성 후보

## 4. 결합 탐색

- 이동 유입과 카드 이용건수·금액의 관계
- 이동시간이 유사한 목적지 간 상권 특성 비교
- 외부 유입/소비가 높은 목적지의 공통 특성
- 실제 유입과 baseline 기대 유입의 잔차 후보(Hidden Destination)

## 5. 비교 기준선

- 이동시간 오름차순
- 과거 유입량 내림차순
- 목적지 전체 인기순

향후 모델은 동일한 시간 분할에서 Recall@K, NDCG@K, MRR 및 coverage로 기준선과 비교한다.

## 품질 원칙

- 평균과 함께 분포, 효과크기, 95% CI를 제시한다.
- 시계열 검증에서는 미래 관측을 학습에 넣지 않는다.
- 통계적 연관성을 인과로 서술하지 않는다.
- 집계자료 결과를 개인 수준 행동으로 일반화하지 않는다.
