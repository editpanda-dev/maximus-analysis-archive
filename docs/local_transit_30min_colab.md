# ODsay 없는 30분 대중교통 도달권 실행 안내

## 현재 확보한 공식 원본

- 서울시 버스 노선별 정류소 정보(2026-09-02): 노선 ID, 정류소 순서, 좌표
- 서울시 노선별 정류장 구간별 평균 운행시간(2026-08-24~30): 시간대별 구간 소요시간
- 서울교통공사 도시철도 열차운행시각표(2026-06-16): 1~9호선 평일·주말 열차시각표
- 서울시 역사마스터(2026-09-02): 역사 ID, 노선명, 좌표
- 동대문구 출발지 334개와 서울 행정동 경계 427개

완성 GTFS를 따로 구할 필요는 없다. `build_seoul_transit_network.py`가 공식 원본을 공통 네트워크 테이블로 변환하고, `static_multimodal_accessibility.py`가 30분 도달권을 계산한다.

## 분석 모형

현재 모형은 10시 기준 버스 구간시간 중앙값과 평일 지하철 시각표에서 계산한 역간시간 중앙값을 사용한다. 출발지에서 정류장까지 최대 600m, 환승 도보는 최대 250m, 보행속도는 초당 1.2m로 설정했다. 버스 최초 탑승 대기시간은 300초, 지하철은 180초, 노선 변경에는 120초를 추가한다.

따라서 이 결과는 지도 앱의 특정 시각 실시간 길찾기 결과가 아니라, 공식 운행자료에 기반한 시간대 평균 접근성 모형이다. 모든 가정은 `model_assumptions.csv`에 기록된다.

## Colab에서 할 일

1. 프로젝트 폴더를 Google Drive에 올린다.
2. `notebooks/local_transit_30min_colab.ipynb`를 Colab으로 연다.
3. Drive 연결 셀에서 `PROJECT_DIR`만 실제 경로로 수정한다.
4. 원본 파일 검사, 네트워크 변환, 334개 출발지 계산 셀을 순서대로 실행한다.

별도 API 키, ODsay 호출, GTFS 업로드는 필요 없다.

## 후보 행정동 판정

출발지 334개 가운데 한 곳에서만 도달해도 포함하는 합집합 기준은 후보가 과도하게 늘어난다. 1차 분석에서는 다음 세 기준을 함께 보고 민감도 분석한다.

- 넓은 후보군: 출발지의 25% 이상에서 30분 내 도달
- 기본 후보군: 출발지의 50% 이상에서 30분 내 도달
- 안정 후보군: 출발지의 80% 이상에서 30분 내 도달

초기 10시 고정가정 모형에서는 각각 195개, 139개, 67개 행정동이었다. 실제 운행자료로 보정하고 운행횟수가 0인 노선을 제외한 50% 기준 후보는 08시 172개, 14시 153개, 19시 168개이며, 세 시간대 모두 기준을 충족한 공통 후보는 153개다.

## 한계와 다음 검증

- 버스는 실제 출발시각표가 아니라 시간대 평균 구간시간과 가정한 대기시간을 사용한다.
- 지하철 시간표 458개 역·호선 노드 중 454개를 역사 좌표와 자동 매칭했다. 온수, 쌍용, 신창, 평택지제 4개는 명칭 중복 또는 개정 문제로 보류했다.
- 직선거리 기반 도보 연결이므로 실제 보행로보다 짧게 계산될 수 있다.
- 알려진 OD 구간을 지도 서비스와 표본 비교하고, 보행 우회계수 민감도 검사를 마친 후 보고서 확정 수치로 사용한다.
