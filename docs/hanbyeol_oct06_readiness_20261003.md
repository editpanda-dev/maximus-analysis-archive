## 작업 순서

1. **팀 공통 분류 결정:** 김건우의 식사 점수에서 `CS100005 제과점`을 카페 이관과 동시에 빼고 버전을 기록한다. 관광특구 6개는 원본 분석에서 유지하고 추천 화면에서 광역 권역 참고로 표시한다.
2. **보행로 그래프 확보·검수:** EPSG:5186 노드·합법적 보행 간선과 시설 출입구 연결을 확보한다. `scripts/build_hanbyeol_walk_access.py`로 시설-상권 거리와 400/500/600m 민감도를 산출한다. 거리 계산이 안 된 시설은 `unknown`으로 둔다.
3. **시설 증거 판정:** `c_stay_s4_evidence_review.csv`의 URL·인용·검토자·시각을 채워 좌석과 학습 허용을 판정한다. 전체 후보 427개를 검토했다고 주장하지 않는다. 미확인 영역의 커버리지를 보고하고 S4가 부족하면 공부 v1의 최종 순위를 발표하지 않는다.
4. **공부 신호 재구성:** S3a 카카오 POI를 주 공급으로 두고 공식 독서실 S3b를 진단 열로 유지한다. 공공시설의 기존 236개 플래그를 실제 공개·학습 적격 판정으로 다시 집계한다. 두 원천이 같은 점포일 가능성 때문에 합산을 고유 시설 수로 부르지 않는다.
5. **점수·조합·근거 재산출:** 관측 0·매출 미공개·시설 확인 미완료를 분리하고, 동일 모집단 백분위를 사용한다. 카페/공부 Top 20, 카페+공부, 식사+카페+공부, 상위 시설과 경로 근거, 지도 순서로 갱신한다.
6. **최종 QA·발표 전달:** 786행과 고유 `area_code`, 하위분류 합계, 400/500/600m 포함 관계, 점수 0~100, 매출 상태와 순위 분리, 상권 크기 보정 전후 Top 10, 제과점 중복 0, 관광특구 기준, 시설 출처·기준일·근거를 기록한다. 최종 점수가 준비되지 않은 부분은 발표에서 기준선·한계로 표시한다.
