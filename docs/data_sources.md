# 데이터 출처 및 감사 체크리스트

## B078 수도권 생활이동

- 출처: 서울특별시 빅데이터캠퍼스
- 확인 기간: 2023-01 ~ 2026-06
- 원 단위: 기준일 × 출발 250m 격자 × 도착 250m 격자 × 시간/목적 × 성·연령 집계
- 주요 값: 이동량, 평균 이동거리, 평균 이동시간
- 접근: 폐쇄망, 결과 반출심사 필요
- 사전 확인: 좌표계, 시간 코드 정의, 성·연령 열의 집계 방식, 소수 이동량 처리, 목적 코드, 행정동 변환용 격자 중심점

## B079 서울시민 업종별 카드소비

- 출처: 서울특별시 빅데이터캠퍼스·신한카드
- 확인 기간: 2021-01 ~ 2026-06
- 원 단위 후보: 기준일 × 고객지역 × 가맹점지역 × 업종대분류
- 주요 값: 카드이용건수, 카드이용금액
- 접근: 폐쇄망, 결과 반출심사 필요
- 사전 확인: 고객/가맹점 지역 코드 수준, 업종 코드북, 비식별·반올림 규칙, 0과 결측 구분, 전체 소비 대비 포착률

## 서울시 상권분석서비스

- 출처: 서울 열린데이터광장·서울신용보증재단
- 원 단위 후보: 기준연분기 × 상권코드 × 서비스업종
- 주요 값: 점포·프랜차이즈·개폐업, 추정매출, 상주·직장·생활인구, 집객시설
- 접근: 공개 데이터
- 사전 확인: 분기별 상권 경계/코드 변경, 업종 개편, 좌표계, 결측/비공개 처리

## 선택 확장 데이터

- 교통: 역·정류장 좌표, 환승역, 승하차량
- 관광·POI: TourAPI, 소상공인 상가업소
- 날씨: 기상청 관측자료
- 제품 단계: TMAP/ODsay 등 실시간 교통 API

## 공통 schema audit

각 원천에서 아래를 표로 기록한다.

| 항목 | 확인 내용 |
|---|---|
| 파일 | 파일명, 기간, 크기, 인코딩, 구분자 |
| grain | 한 행이 의미하는 최소 관측 단위 |
| key | 고유키 후보와 중복 건수 |
| time | 날짜·시간·분기 정의와 시간대 |
| geography | 지역코드 버전, 공간 수준, 좌표계 |
| measure | 단위, 집계 방식, 0/결측/마스킹 |
| join | 연결키, many-to-many 여부, 누락률 |
| governance | 접근권한, 반출·공유·커밋 가능 범위 |

## 즉시 필요한 샘플

각 데이터의 실제 값이 아니라 스키마 검증이 가능한 최소 샘플을 확보한다. 반출 규정을 충족한 경우에만 헤더, dtype, 비식별 예시 행, 코드북을 `data/external/` 또는 별도 승인 위치에 둔다. 실제 값이 없는 동안 합성값을 실데이터처럼 사용하지 않는다.
