# 막시무스 모델 학습 피드백과 다음 주 계획

작성일 2026년 10월 1일  
실행 기간 2026년 10월 5일부터 10월 7일까지  
목적 중간발표 전에 규칙 기반 추천과 학습 기반 목적지 선택모형의 첫 비교 결과를 만든다

## 모델 학습 피드백

기존 계획에 있었던 조건부 로짓, LightGBM 랭커, Recall at 5와 NDCG at 5 평가가 현재 진행 상황에서 빠져 있다. B078과 B079 캠퍼스 원본을 확보하지 못했다는 이유로 모델 학습 전체를 미루면 프로젝트가 데이터 정제와 규칙 점수 단계에 머물게 된다.

따라서 다음 주에는 공개 수도권 생활이동 데이터의 행정동과 시간대별 이동량을 목적지 선택 라벨의 대체값으로 사용한다. 이 라벨은 개인의 실제 방문 목적을 직접 나타내지 않으므로 최종 추천 성능이 아니라 행정동 단위 이동량 예측 기준선으로 명확히 한정한다.

## 학습 단위와 라벨

- 출발 단위는 동대문구 출발 행정동 또는 출발 거점이다
- 도착 라벨은 시간대별 도착 행정동 이동량이다
- 후보는 해당 출발지에서 30분 안에 도달 가능한 목적지로 제한한다
- 공식 상권 피처는 상권과 가장 많이 겹치는 도착 행정동으로 집계하거나, 행정동 안 후보 상권의 합계와 평균으로 변환한다
- 식사, 카페, 공부, 쇼핑, 여가문화 목적별 점수는 목적지 설명 피처로 사용하되 실제 목적 라벨처럼 취급하지 않는다

공개 생활이동 데이터가 제공하는 이동 목적 컬럼이 확인되면 목적별 모델을 분리한다. 목적 구분이 없으면 전체 이동량 예측과 목적 점수 기반 후처리를 분리해 보고한다.

## 다음 주 학습 순서

### 기준선 1 규칙 기반 랭킹

현재 Purpose Score v2로 후보를 정렬한다. 학습모형과 비교할 최소 기준선이다.

### 기준선 2 다항 로지스틱 회귀

출발지, 시간대, 접근성, 공급, 소비, 목적별 피처로 도착 행정동 선택 확률을 예측한다. 계수 방향을 확인해 어떤 피처가 이동 선택과 연결되는지 해석한다.

### 모델 3 LightGBM 랭커

같은 출발지와 시간대의 후보 목적지를 하나의 query group으로 묶고 실제 이동량 또는 선택 여부를 relevance label로 사용한다. 목적지별 순위를 직접 학습하고 규칙 기반 점수와 비교한다.

조건부 로짓은 데이터 long format과 대안별 피처가 안정적으로 완성되면 함께 실행한다. 시간이 부족하면 다항 로지스틱 회귀와 LightGBM 랭커를 우선한다.

## 평가 설계

무작위 행 분할은 같은 출발지와 인접 시점이 학습과 평가에 동시에 들어가 누수를 만들 수 있으므로 사용하지 않는다.

- 시간 홀드아웃은 이전 기간으로 학습하고 가장 최근 기간으로 평가한다
- 출발지 홀드아웃은 일부 동대문구 출발 행정동을 통째로 평가용으로 제외한다
- Recall at 5는 실제 이동량 상위 목적지 가운데 추천 Top5가 얼마나 포함했는지 측정한다
- NDCG at 5는 실제 이동량이 높은 목적지가 추천 상단에 배치됐는지 측정한다
- MRR은 첫 실제 상위 목적지가 몇 번째 추천에 등장하는지 측정한다

규칙 기반, 다항 로지스틱, LightGBM에 동일한 후보군과 동일한 분할을 사용한다.

## 가중치 학습과 라벨 한계

현재 70대30 가중치는 설명 가능한 기준값이지 학습된 최적값이 아니다. 공개 생활이동 데이터를 사용해 가중치를 조정할 수 있지만, 이동량이 만족도나 개인의 방문 목적을 직접 뜻하지 않는다는 한계가 있다.

B078 또는 동등한 개인 이동 목적 라벨을 확보하면 다음 단계에서 목적지 선택모형을 다시 학습한다. B079 유입지별 소비 원본을 확보하면 방문이 실제 소비로 이어졌는지 별도의 전환 모델로 검증한다. 원본 확보 전에는 이동량 예측 성능을 개인화 추천 성능으로 표현하지 않는다.

## 다음 주 완료 기준

- 공개 생활이동 데이터의 출발, 도착, 시간대, 이동량 스키마 확인
- 후보 목적지 long format 학습 테이블 생성
- 규칙 기반, 다항 로지스틱, LightGBM 결과 산출
- 시간 홀드아웃과 출발지 홀드아웃 평가
- Recall at 5, NDCG at 5, MRR 비교표
- 목적지 3개 이상에 대한 모델 설명값 또는 계수 해석
- 데이터와 라벨의 한계를 포함한 중간발표용 결론 작성

## 중간발표에서 사용할 약속

이번 주까지 후보군, 목적 taxonomy, 공간 집계, 결측 처리, 점수식을 정리해 학습 가능한 피처마트를 완성한다. 다음 주에는 공개 생활이동 데이터를 임시 라벨로 사용해 규칙 기반 기준선과 다항 로지스틱 및 LightGBM 랭커를 같은 조건에서 비교하고, Recall at 5와 NDCG at 5를 포함한 첫 모델 성능을 제시한다.
