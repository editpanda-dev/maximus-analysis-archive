## 3. 단체 회식 · 감성 모임 정의 (11-18)

인원수만으로는 둘이 갈리지 않는다. 그래서 자리, 먹는 방식, 소리 세 기준으로 나눴다.

| | 단체 회식 | 감성 모임 |
|---|---|---|
| 자리 | 단체석 · 룸 · 큰 홀 | 작은 테이블 |
| 먹는 방식 | 가운데 놓고 나눠 먹음 | 조금씩 시켜 오래 머묾 |
| 소리 | 떠들어도 됨 | 분위기가 고르는 이유 |
| 예 | 부서 10명 예약 | 친구 넷이 두세 시간 |

두 기준에 모두 맞으면 하나만 '예'로 둔다. 옛 정의로 찍은 라벨은 섞지 않는다.

단체 회식은 라벨로 학습하지 않고 **규칙 점수**를 쓴다. 점수는 '단체모임 하기 좋아요'·'매장이 넓어요'·'룸이 잘 되어있어요' 칩 비율과 log 면적을 각각 전체 순위로 바꿔 평균한 값이다.

## 5. v5 (11-23 ~ 24, `build_tags_v5.py`)

v4와 같은 피처와 방법을 쓰고, 라벨과 대상을 넓혔다.

**5회차 라벨 = 첫 능동 학습** (`build_label_round.py`, `build_r5_group.py`)

| 묶음 | 가게 | 뽑은 이유 |
|---|---|---|
| 애매 | 45 | v4가 0.3~0.7로 본 가게. 가장 어려운 문항 |
| 무작위 | 25 | 모형이 고르지 않은 가게. 편향 없는 점검용 |
| 다시 찍기 | 15 | 내 라벨의 일관성 점검. 학습에는 쓰지 않음 |
| 단체 경계 | 20 | 단체 점수 상위 10 · 경계 6 · 좁은 모임집 4 |

**바뀐 점**
- 태그 대상 기준을 MIN_N 20에서 10으로 낮췄다(칩 달린 리뷰 10건 이상). 그래서 대상이 24,370곳으로 늘었고, Jev를 12,624곳에 더 물었다(약 $0.78).
- 단체 회식 기준선을 다시 잡았다. 새 정의로 찍은 라벨 44곳에서 점수 AUC가 0.81이었다. v4 기준(아님 ≤ 0.6)에서는 '아님' 28곳 중 12곳이 실제로 '예'였다. 그래서 해당 = 점수 ≥ 0.65이고 면적 ≥ 50㎡, 아님 = 점수 ≤ 0.4로 바꿨다. 이 기준에서 해당 15곳 중 87%가 실제로 '예'였다.
  - **주의**: 0.65는 순위가 아니라 점수라서 v4(상위 10%)보다 넓다. 24,370곳 중 4,567곳(19%)이 단체 회식이 됐다. 라벨 표본이 단체 후보 위주였기 때문이다. **임시값**이고, 무작위 라벨로 다시 잡아야 한다.

**결과**: 느좋 4,913곳. 5회차 시험셋 가중 AUC 0.82(학습에 안 쓴 가게). 가게 단위 CV 0.78, 확정 구간 0.87.

| 태그 | 해당 가게 |
|---|---|
| 느좋 | 4,913 |
| 단체 회식 | 4,567 (임시 기준) |
| 이색 체험 | 1,377 |
| 데이트·기념일 | 1,301 |
| 가성비 혼밥 | 1,119 |
| 감성 모임 | 1,116 |
| 야장·야외석 | 796 |
| 혼밥 감성 · 가성비 감성 | 254 · 242 |
| 조용한 작업 공간 · 카공·스터디 모임 | 33 · 15 (식당에는 거의 없음) |

**넣어 보고 뺀 피처** (`eval_tags_v5.py`, 5회차 시험셋 가중 AUC)

| 피처 묶음 | AUC |
|---|---|
| v3 피처 (채택) | 0.823 |
| + 리뷰 본문 TF-IDF | 0.827 |

차이가 없어서 단순한 v3 피처를 유지했다.

**느좋 판정의 정밀도**: 학습에 안 쓴 4·5회차 가게 116곳 기준으로, 확률 0.7 이상이면 90%, 0.5~0.7이면 78%가 실제 느좋이었다. 0.3 미만에도 37%가 느좋이라 재현율이 약점이다. 5회차 무작위 25곳만 보면 0.5 이상 11곳 중 10곳이 맞았고, 0.5 미만 14곳 중 6곳이 느좋이었다.

## 6. 방문 정보 1차 평가 (11-25, `eval_visit_info_v0.py`)

11-23부터 네이버 리뷰의 방문 정보 칩(혼자·연인·친구·데이트·친목·회식·예약 등)과 방문 시각도 모은다. 11-25 기준 식사 18,660곳, 리뷰 35만 건을 모았고, 그중 80%에 칩이 있다. 칩 코드와 한글 이름이 어긋난 행이 있어서(예: `v_significant_other:아이`) 화면에 보이는 한글 이름만 썼다.

| 태그 | 라벨 문항 | 방문 정보만 | v3 | v3 + 방문 정보 | 차이 95% 구간 |
|---|---|---|---|---|---|
| 느좋 | 443 | 0.70 | 0.880 | 0.881 | −0.003 ~ +0.005 |
| 감성 모임 | 178 | 0.84 | 0.893 | 0.902 | −0.001 ~ +0.020 |
| 데이트·기념일 | 160 | 0.79 | 0.883 | 0.893 | −0.006 ~ +0.026 |
| 가성비 혼밥 | 108 | 0.82 | 0.878 | 0.884 | −0.011 ~ +0.030 |

가게 단위 5겹 CV이고, 방문 정보가 5건 이상인 라벨 가게만 썼다. 결과 파일은 `visit_info_eval_v0.csv`.

- **방문 정보만으로도 태그를 상당히 맞힌다**(0.70~0.84). 리뷰 칩과 독립된 신호인데 라벨과 같은 방향으로 움직인다. 데이트 가게는 데이트 칩 38% 대 21%, 가성비 혼밥 가게는 혼자 칩 30% 대 8%다. 라벨이 실제 방문 행동과 맞다는 근거로 쓸 수 있다.
- **v3에 더하면 +0.001~+0.010이고, 95% 구간이 모두 0을 포함한다.** 지금 표본으로는 유의하지 않다.
- **병목은 수집이 아니라 라벨 수다.** 라벨 가게 367곳 중 352곳에 이미 방문 정보가 있다. 남은 수집(식사 11,642곳, 약 17시간)이 끝나도 이 비교의 표본은 거의 늘지 않는다.
- 감성 모임 구간의 하한이 −0.001이라 가장 가깝다. 지금 구간 폭으로 볼 때 감성 모임은 라벨 약 200문항, 데이트는 약 400문항이면 +0.01 차이를 가릴 수 있다.
- 방문 정보가 쓸모 있을 곳은 따로 있다. (1) 칩이 적어 v3를 못 쓰는 가게, (2) '회식' 칩으로 단체 회식 규칙 점수를 보강, (3) 라벨 없는 가게의 약한 라벨(데이트 칩 비율로 데이트 후보 뽑기).
