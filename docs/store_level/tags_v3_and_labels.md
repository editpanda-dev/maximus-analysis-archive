# 점포 태그 v1 ~ v3와 라벨

김건우 · 2026-11-13 ~ 11-16 · 스크립트 `scripts/members/gunwoo/workspace_2026_11/` · 결과 `data/processed/store_level/tags_v3/`

## 1. 왜 했나

상권을 추천해도 "거기서 어디 가지?"가 남는다. 상권 안 식당에 목적 태그를 붙여 2단 추천(상권 → 점포)을 만든다. 공공데이터판 v0는 네이버 키워드 집계가 429로 막혀 리뷰 신호가 비어 있었다. 그래서 네이버 플레이스 방문자 리뷰를 직접 모았다(크롤러는 PR #6).

태그 11개: 느좋, 감성 모임, 데이트·기념일, 혼밥 감성, 가성비 감성, 가성비 혼밥, 단체 회식, 카공·스터디 모임, 조용한 작업 공간, 이색 체험, 야장·야외석.

## 2. 재료

- 리뷰: 가게당 최대 20건. 판정 대상 4,804곳(리뷰가 충분한 식사 점포)
- 키워드 칩: 네이버 리뷰에 붙는 공식 칩("분위기가 좋아요", "혼밥하기 좋아요" 등)을 테마 12개로 묶었다. 테마: 감성·조용·특별함·가성비·대화·모임·혼자·편의 등
- 테마 점수: 가게마다 테마별 칩 선택 비율을 **업종 안 순위**와 전체 순위로 바꾼 값. 치킨집과 카페를 같은 잣대로 비교하지 않으려는 것
- 인허가 매칭(`match_localdata.py`): 서울시 음식점 인허가와 붙여 매장 면적·업태(감성주점 등)를 얻는다
- 프랜차이즈(`build_franchise_flags.py`): 전국 상가정보의 상호명·지점명으로 판정. 흔한 이름(고향식당)은 지점명이 거의 없어서 걸러진다

## 3. 라벨

모델 판정을 가리고 "이 가게가 이 태그에 해당하나" 예/아니오로 직접 찍었다(`labels_r1_r4.csv`).

| 회차 | 가게 | 내용 |
|---|---|---|
| 1 | 120 | 태그마다 모델 기준 해당·경계·비해당을 섞어 뽑음 |
| 2 | – | 가게 대신 업종×태그 허용표와 추천 제외 후보(배달 전문·공간 대여·감성주점) 검토 |
| 3 | 107 | v1 확인용 |
| 4 | 55 | 학습에 안 쓴 처음 보는 가게. 검증용 |
| 합계 | 282곳 | 602문항, 그중 느좋 278 |

1회차 메모에서 나온 규칙: 식당에서 "오래 머무르기 좋아요"는 술자리를 뜻한다(횟집이 '조용한 작업 공간'으로 잡힌 원인). 업종 평균이 0에 가까우면 한두 번만 골라도 업종 안 상위가 된다. 그래서 업종×태그 허용표를 먼저 둬서 말이 안 되는 조합을 막았다.

## 4. 모델 변천

| 판 | 방법 | 성능 |
|---|---|---|
| 옛 느좋 지수 | 칩 단순 합 | 느좋 AUC 0.60 |
| v1 | 로지스틱: 감성·조용·특별함 전체 순위 (라벨 117) | 느좋 AUC 0.90 (5겹 CV) |
| v2 | + 가성비(−), 면적·업태, 프랜차이즈, 업종 보정, 허용표 (라벨 223) | 느좋 AUC 0.89, 임계 0.6에서 정밀 0.86·재현 0.80 |
| v3 | 태그별 로지스틱: Jev 원자 판단 15개 + 테마 점수 12개 + 프랜차이즈 | 442문항 CV 정확도 0.80 |

라벨에서 느좋을 가르는 건 맛·친절·청결이 아니라 분위기와 특별함이었다.

### Jev가 하는 일

Jev(TypeSafe System One)는 질문을 주면 확률로 답하는 판정 모델이다. 가게 리뷰를 넣고 원자 질문 15개를 묻는다(`llm_judge/jev_questions.py`). 예: 인테리어를 칭찬하나(interior), 분위기 묘사가 있나(mood), 조용한가(quiet), 특별한 경험인가(special), 커플 방문인가(couple), 가성비 언급(value), 양(portion), 혼자(solo), 단체(group), 넓은가(spacious), 술(alcohol), 공부(study), 체인 느낌(chain), 빨리 먹고 나오나(quick), 맛 얘기만 하나(taste_only). 결과는 `jev_atomic_v1.csv`(4,804곳 × 15, 입력 약 755만 토큰).

Jev는 태그를 직접 정하지 않는다. 원자 판단 15개를 피처로 쓰고, 태그 결정은 라벨로 학습한 로지스틱이 한다.

### Jev를 넣고 뺀 차이

| 비교 | Jev 없음 | Jev 있음 |
|---|---|---|
| 같은 442문항 5겹 CV | 테마 점수만 0.79 | Jev 원자 + 테마 0.80 |
| 처음 보는 4회차 91문항 | v2 0.71 | v3 0.74 |
| 4회차 느좋 55문항 | v2 0.64 | v3 0.73 |

다른 판정기(같은 442문항): Jev 직접 질문 0.77, K-EXAONE API 0.76, 임베딩 0.75, 로컬 Qwen3.5 9B·EXAONE 3.5 7.8B 0.68. 4회차에서 Claude가 직접 판정하면 0.55였다. 방법 간 차이는 통계적으로 유의하지 않다(p 0.10~0.45).

**뜻**: 성능 대부분은 테마 점수에서 나온다. Jev는 전체 정확도로 1~3%p를 더하고, 느좋에서는 처음 보는 가게 기준 9%p를 더했다(단, 55문항이라 오차가 크다). 교차검증 0.80은 낙관적이었고 실제는 0.73~0.75로 본다.

### v3 결과 (`store_tags_v3.csv`)

- 확률 0.7 이상 해당, 0.3 이하 아님, 사이는 애매(사람 확인)
- 4,804곳, 느좋 936곳
- 4회차 기준 확정 구간 64%, 그 안의 정확도 0.83. 애매 구간 0.58
- 라벨이 적은 태그(단체 회식·야장·이색 체험)와 제외·프랜차이즈 표시는 v2 규칙을 그대로 쓴다

**약점**
- 느좋 재현율이 낮다. v2가 '아님'이라 한 35곳 중 49%가 실제 느좋이었다.
- 업종에 끌려간다. 국·탕 느좋 0%, 경양식 94%.
- 라벨러가 한 명이고, 라벨 표본을 모델이 골라서 편향이 있다.
- 정답을 매길 때 보는 화면도 같은 리뷰라 순환 구조다.

## 5. 다음: 라벨로 직접 배우는 모형

1. **라벨러 간 일치율.** 장한별·지우진에게 같은 55곳(내가 찍은 30곳 + 무작위 25곳)을 모델 판정 없이 물었다. 사람끼리 일치율(Cohen κ)이 모델이 올라갈 수 있는 천장이다. 사람끼리도 0.75면 지금 모델은 이미 천장 근처고, 0.9면 개선 여지가 크다.
2. **Jev 없는 지도학습.** 피처를 직접 만든다.
   - 리뷰 본문: 형태소 분석 후 TF-IDF(단어 단위 신호, 예: "조명", "웨이팅", "회식")
   - 키워드 칩 비율(테마 12개, 업종 안 순위)
   - 메뉴판: 대표 메뉴 가격, 가격 범위, 메뉴 수, 술 메뉴 비율(수집 중)
   - 인허가: 면적, 업태 / 프랜차이즈 여부 / 네이버 리뷰 총수(인기도)
   - 모형: 계수를 읽을 수 있는 로지스틱(L1)과 GBM을 같이 학습하고 4회차·5회차로 평가
   - Jev 점수는 피처 하나로만 넣고, 넣은 판과 뺀 판을 비교해 Jev가 실제로 더하는 몫을 잰다
3. **업종 효과 걷어 내기.** 업종을 고정효과(또는 계층 로지스틱)로 넣는다. "경양식이라 느좋"과 "이 가게라 느좋"을 나누고, 추천은 업종 안 상위로 한다.
4. **능동 학습.** 5회차 85곳(애매 45 · 무작위 25 · 다시 찍기 15)으로, 애매한 곳만 묻는 방식이 무작위보다 라벨당 얼마나 더 올리는지 학습 곡선으로 비교한다. 다시 찍기 15곳은 내 라벨의 일관성을 잰다.
5. **행동으로 검증.** 상권별 태그 비율이 그 상권의 20대 유입이나 SERP-v1의 U를 설명하는지 생활이동 OD로 회귀한다. 태그가 리뷰 말투가 아니라 실제 방문 차이와 이어지는지 보는 단계다.

## 6. 아이디어: 날씨·상황 반영 (구현 전)

- 날씨: 비 → 파전·막걸리, 추위 → 국물, 더위 → 냉면·빙수, 날 좋은 저녁 → 야장. 4,804곳 중 메뉴와 리뷰 신호가 둘 다 있는 가게는 비 15곳, 추위 200곳, 더위 41곳, 야장 태그 185곳이다.
- 계산: 최종 = 목적 점수 × (1 + Σ w·친화도·날씨 조건), w 0.15~0.3. 날씨는 순서를 살짝 바꾸는 가산이고, 목적에 안 맞는 가게를 끌어올리지 않는다.
- 상황 트리거(리뷰에서 찾음): 해장(리뷰 3,382건), 생일·기념일(2,921), 새벽·심야(1,737), 몸보신·복날(1,618) 등.
- 막힌 점: 가게당 최근 리뷰 20건이라 계절 효과를 데이터로 검증하지 못한다. 메뉴판 수집이 끝나면 메뉴 신호부터 정확해진다.
