# 부록 - 논문 규칙을 응용한 발견형 상권 태그

작성: 김건우 · 2026-10-06 · 상태: **탐색 부록 (10/6 점수 기준선 범위 밖)**

> 이 부록은 10/6 마감 산출물(식사·쇼핑 점수 기준선 v1)과 별개다. 여기서 만든 태그는 v1 점수·순위에 **반영하지 않았다**. 팀 제안 전 시범 분석이며, 채택 여부는 중간발표 이후 팀에서 정한다.

## 1. 출발점

Yang et al. (2026), *The characteristic analysis and pattern classification of Beijing's commercial districts based on multi-source geographical big data*, Urban Informatics 5, 26. https://doi.org/10.1007/s44212-026-00116-z

베이징 5환 안 67개 상권을 POI·휴대폰 체류 인구·이동 OD로 분류한 연구다. 네 축으로 나눈다.

- 규모(POI 수 + 활력 순위 합)
- 업종 구성(기능 엔트로피)
- 시간 리듬(평일·주말 × 낮·저녁 활력)
- 방사력(방문자 출발지 분포)

우리 점수 기준선은 "공급이 많고 매출이 높은 곳"을 위로 올린다. 그래서 공급 대비 결제가 몰리는 곳이나 리듬이 튀는 곳은 순위에 드러나지 않는다. 이 부록은 논문 규칙 중 공개 데이터로 재현되는 부분을 옮겨서, 기존 순위에 보이지 않는 상권을 **태그**로 꺼내는 시도다.

## 2. 데이터 대응

| 논문 | 이 부록 | 비고 |
|---|---|---|
| 휴대폰 체류 인구(활력) | 카드 결제 건수, 2025년 1–4분기, 상권×업종 | 방문자가 아니라 결제. 주민 일상 소비가 섞임 |
| 평일·주말 × 낮·저녁 상대 활력 | 주말 매출 비중, 17–24시 매출 비중, 10·20대 매출 비중 | |
| 업종 엔트로피 | 서울시 100대 업종 점포 수 엔트로피 | 논문은 4기능 엔트로피 |
| 규모 등급 | 공식 점포 수 순위 + 결제 건수 순위 합 | 논문 규칙 그대로 |
| 방사력 | 없음 | B078 OD 필요 |
| (추가) 거리 보행자 수 | 서울 열린데이터 상권 길단위 인구(OpenAPI) | 선택 입력, 원값은 저장소에 넣지 않음 |

## 3. 규칙

관광특구 6곳은 다른 후보 상권을 품고 있어서 태그 대상에서 뺐다(780곳). 규모 등급과 전문시장형을 뺀 모든 태그는 **2025년 4분기를 포함해 4개 분기 중 3개 이상**에서 조건을 만족해야 붙는다.

| 태그 | 규칙 | 논문 대응 |
|---|---|---|
| 도시핵심 / 지역핵심 | 점포 수 순위 백분위 + 결제 건수 순위 백분위의 합 상위 10% / 10–25% | 규모 등급 |
| 목적형 결제 | 업종 구성 기대 대비 결제 건수 1.8배 이상(상권 중앙값 = 1). 매출 공개 점포 60% 이상 | 공급 대비 활력 불일치 |
| 결제 건수 적음(주의) | 같은 비율 1/1.8 이하 | 같음 |
| 저녁형 / 주말형 / 10·20대형 | 해당 매출 비중이 같은 상권 유형 안에서 +2SD 이상 | 시간 이질성 |
| 전문시장형 | 업종 엔트로피가 평균 −2SD 미만 | 전문 비교구매형 |
| 유동 대비 결제 유형 | 점포당 거리 보행자 z와 보행자 1인당 결제 z(상권 유형 안)로 ±0.5SD 사분면 | 추가 |

기대 결제 건수 = Σ(업종별 점포 수 × 같은 업종·같은 상권 유형의 서울 점포당 결제 건수 중앙값)이고, 매출이 공개된 칸만 쓴다. 분식처럼 원래 결제 건수가 많은 업종이 많은 상권이 저절로 위로 오르지 않게 하려는 장치다.

## 4. 결과

### 4-1. 목적형 결제 31곳

- 이 중 **22곳은 식사·쇼핑 v1 순위 50위 밖**이다.
- 4분기 순위와 1분기 순위의 상관은 0.93으로 안정적이다.
- 거리 보행자 1인당 결제 건수 중앙값은 목적형 2.55, 나머지 0.76으로 약 3.4배다. 사람이 많아서가 아니라 온 사람이 확실히 사는 곳이라는 뜻이다.

| 기존 순위에 안 보이던 예 | 기대 대비 | v1 최고 순위 |
|---|---:|---:|
| 쌍문역 1번(쌍리단길) | 3.5배 | 254위 |
| 성신여대입구역 4번 | 2.7배 | 434위 |
| 마들역 | 2.6배 | 333위 |
| 서울과학기술대 | 2.2배 | 174위 |
| 방학역 1번 | 2.1배 | 103위 |
| 동대문문구완구거리 | 6.0배 | 51위 |
| 외대앞역 1번 (동대문구) | 2.3배 | 116위 |

청량리종합·청과물·농수산물시장, 경동시장, 노량진처럼 장보기 시장도 많이 걸린다. 이 시장들은 1회 방문에 여러 점포에서 결제하는 구조라서, 전통시장은 따로 떼어 봐야 한다.

### 4-2. 리듬 태그

| 태그 | 수 | 거리 보행자로 교차 확인 (10/1 분석) | 예 (v1 순위 밖) |
|---|---:|---|---|
| 10·20대형 | 44 | 양호 (결제 +2SD 상권의 86%가 보행자 비중도 평균 이상) | 경희대삼거리, 이대 앞 스타트업 상점가, 서울시립대, 회기시장, 고려대역 6번 |
| 저녁형 | 14 | 보통 (68%) | 중랑역 2번, 전농119안전센터, 경희대삼거리, 홍제역 4번 |
| 주말형 | 11 | 약함 (50%) | 도봉산역 1번, 굽은다리역 3번, 아차산역 5번 |

10·20대형은 태그로 바로 쓸 만하다. 저녁형은 보조 정보로, 주말형은 계절 영향이 커서 참고로만 쓴다. 동대문구 안에서는 10·20대형 10곳(회기역, 회기시장, 경희대삼거리, 서울시립대, 외대앞역 1번 등)이 걸려서, "동대문구 대학생" 시나리오와 직접 연결된다.

### 4-3. 결제 건수 적음 13곳 (추천 주의 표시)

평화시장(남평화·제일평화), 숭례문수입상가, 아현가구거리, 서울약령시장, 학동사거리, 강남을지병원 등이 해당한다. 현금·업체 거래가 많거나 가구·명품처럼 1건 금액이 큰 품목이라 건수가 적게 잡히는 곳이다. **v1 식사+쇼핑 8위 학동사거리가 여기에 걸린다.** 순위 자체가 틀렸다는 뜻은 아니지만, 매출액 기반 순위와 결제 건수 기반 신호가 엇갈리는 상권이라 설명 카드에 이 점을 함께 적어야 한다.

### 4-4. 전문시장형 34곳, 그리고 방산·대림은 못 잡는다

동대문상가 A–D동, 평화시장류, 세운상가, 테크노상가, 자동차부품상가, 용산전자상가가 걸린다. 논문의 전문 비교구매형 규칙이 서울에서도 작동한다.

그러나 v1 공격 점검에서 남겨 둔 **방산시장과 대림상가는 잡지 못한다.** 방산시장은 업종 엔트로피 3.22로 오히려 평균보다 다양하다. 대림상가(2.27)도 기준선 1.98보다 높다. 대림은 조명용품이 49%를 차지해서 "단일 업종 비중 45% 이상" 같은 보조 규칙이면 걸리지만, 방산은 최대 업종 비중이 12%라 업종 구성으로는 소매 상권과 구별되지 않는다. 9월 메모에서 "엔트로피 규칙으로 바로 판정할 수 있다"고 적었던 것은 틀렸다. 이 두 곳은 수동 검토가 필요하다.

### 4-5. 유동 대비 결제 사분면 (매출 공개 60% 이상 255곳)

| 유형 | 수 | 예 |
|---|---:|---|
| 목적형(사람 적고 결제 많음) | 52 | 경동시장, 청량리청과물시장, 상계역, 성수동카페거리, 용산전자상가 |
| 통과형(사람 많고 결제 적음) | 14 | 회기역, 왕십리역, 동대문역, 안암역, 뚝섬역, 아현가구거리 |
| 번화형 / 한산형 | 3 / 1 | |

통과형은 대부분 환승역 상권이다. 추천에서 빼야 할 곳이라기보다 "지나가며 들르기 좋은 곳"이라는 설명에 쓸 수 있다. 다만 길단위 인구는 거리 보행자만 세서 코엑스·롯데백화점·잠실역 같은 실내·지하 상권은 사람이 적게 잡히고 목적형으로 분류된다.

### 4-6. 규모 등급 안에서 비교하기

v1은 상권 크기가 순위를 좌우하지 않도록 밀도와 특화도로 크기를 보정했다. 논문은 반대로 규모를 지우지 않고 **등급 축**으로 남긴 뒤 등급 안에서 비교한다. 같은 v1 점수를 등급별로 나눠 보면 다음과 같다(`scale_tier_top5_food_shopping.csv`).

| 등급 (상권 수) | 식사 상위 | 쇼핑 상위 |
|---|---|---|
| 도시핵심 (74) | 종각역, 방이동먹자골목, 광화문역 | 명동역, 명동거리, 종로5가역 |
| 지역핵심 (111) | 종로구청, 남영동 먹자골목, 공릉역 | 방산시장, 성수대교남단, 롯데백화점 |
| 생활권 (557) | 금천교시장, 신당 먹거리골목, 시청역 1번 | 종로신진시장, 대림상가, 을지로4가역 |

"큰 상권이 유리한가"라는 논쟁에는 크기를 지우는 답(v1 밀도·특화도)과 크기를 등급으로 드러내는 답이 있다. 사용자가 "번화가 말고 동네 상권"을 고를 수 있게 하려면 두 번째 방식이 더 직접적이다.

## 5. 한계

- 카드 결제 건수는 방문자 수가 아니다. 주민 일상 소비와 직장인 점심이 섞인다(논문은 휴대폰 체류 인구).
- 방사력(어디서 오는지)은 B078 같은 OD 자료 없이는 만들 수 없다.
- 기대 대비 결제의 기준(업종×상권 유형 중앙값)은 매출이 공개된 칸에서만 계산한다. 공개 비율 60% 미만 상권은 목적형 판정에서 빠진다(780곳 중 4분기 판정 가능 255곳).
- 거리 보행자 수는 실내·지하 상권을 과소 측정한다.
- 태그 기준값(1.8배, +2SD, ±0.5SD)은 논문과 시범 분석에서 정한 값이고, 학습된 값이 아니다.

## 6. 팀 제안 (중간발표 이후)

1. **10·20대형과 목적형 결제를 추천 카드의 보조 태그로** 붙인다. 점수에는 넣지 않는다.
2. **결제 건수 적음은 주의 표시로** 쓴다. 학동사거리처럼 매출액 순위와 엇갈리는 상권을 설명할 때 근거가 된다.
3. **전문시장형은 쇼핑 추천 필터 후보로** 둔다. 방산·대림은 수동 검토 목록으로 따로 관리한다.
4. **규모 등급은 사용자 필터로** 검토한다(번화가 / 동네 상권).

## 7. 재현

```bash
python scripts/build_appendix_discovery_tags.py \
  --street-population <서울 열린데이터 VwsmTrdarFlpopQq CSV>   # 선택
python -m pytest tests/test_build_appendix_discovery_tags.py -q
```

- 길단위 인구는 서울 열린데이터 광장 OpenAPI(`VwsmTrdarFlpopQq`)로 받는다. 인증키와 원본 응답은 저장소에 넣지 않는다. 이 입력이 없으면 4-5절 사분면만 빠지고 나머지는 그대로 계산된다.
- 산출물: `data/processed/appendix_discovery_tags/` (786행 태그표, 등급별 상위표, 요약 JSON)
- 이 분석의 원형은 2026-10-01 저장소 밖 개인 스크립트(`분석/stability.py`, `openapi_analysis.py`)였고, 이번에 저장소 안에서 재현되도록 옮겼다. 목적형 31곳, 사분면 52/14곳, 1인당 결제 2.55 대 0.76이 원형 결과와 일치한다.
