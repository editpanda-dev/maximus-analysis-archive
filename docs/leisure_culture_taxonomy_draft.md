# 여가문화 하위목적 분류 초안 v0

기준일: 2026-09-26  
담당: 지우진  
대상: 동대문구 334개 출발지에서 세 시간대 모두 25% 이상이 30분 안에 접근 가능한 공식 상권 786개

## 1. 이 문서의 역할

현재의 `여가문화`는 하나의 큰 목적이다. 이 문서는 이를 곧바로 최종 추천 점수로 쪼개는 대신, 현재 확보된 POI 피처가 실제로 지지하는 하위목적과 공간 커버리지를 명확히 한다. 이후 팀이 각 하위목적의 가중치와 추가 데이터를 합의할 때 사용하는 기준선이다.

2025년 매출·점포 기반 PATH-v0 순위는 변경하지 않는다. 본 초안의 POI는 2026-09-16 현재 스냅샷이므로, 2025년 예측·검증의 입력으로 사용하지 않는다.

## 2. 하위목적 초안과 포함 기준

| 코드 | 표시명 | 포함 시설 피처 | 제외·유의 사항 |
|---|---|---|---|
| `viewing_exhibition` | 관람·전시 | 박물관, 미술관·갤러리, 영화관, 전시공간 | 단순 상업 매장·서점은 포함하지 않는다. 영화관은 관람 활동으로만 한 번 집계한다. |
| `performance_culture` | 공연·문화활동 | 공연장, 문화센터 | 전시공간과 공연장은 서로 다른 유형으로 유지한다. 문화센터의 실제 프로그램 운영 여부는 현재 스냅샷만으로 확정하지 않는다. |
| `outdoor_park` | 야외·공원 | 공원 | 공원 규모·안전·날씨·행사 여부는 아직 반영하지 않는다. |
| `sports_activity` | 스포츠·활동 | 스포츠시설 | 체육시설의 회원제 여부·예약 가능 여부·세부 종목은 아직 분리하지 않는다. |

각 원천 피처는 정확히 한 하위목적에만 배정한다. 따라서 하위목적 총합은 같은 시설을 여러 목적에 중복 반영하지 않는다.

## 3. 공간 집계 규칙

- 상권 폴리곤 내부와 경계 밖 400m 이내 시설을 합친 `*_buffer400_count`를 사용한다.
- 400m는 상권 내부 경계만 쓰면 실제 도보 이용 가능한 인접 시설을 빠뜨릴 수 있어, 후보 설명용 보조 반경으로 둔 값이다.
- 이 단계의 수치는 상권별 시설 개수와 보유 여부이며, 이용자 방문량·만족도·실제 운영 여부를 뜻하지 않는다.
- POI의 기준일은 2026-09-16이며 `historical_2025_use_allowed=false`다.

스포츠·활동은 커버리지가 낮다. 따라서 이 항목을 다른 세 하위목적과 같은 비중으로 즉시 합산하면 스포츠시설이 적게 수집된 상권을 과도하게 불리하게 만들 수 있다. 10월 6일 점수식에서는 원천 보강 또는 `데이터 제한` 표시 여부를 우선 결정한다.

## 5. 다음 점수식 설계 원칙

최종 하위목적 점수는 아래 세 신호를 분리해 조합한다.

1. **시설 신호**: 해당 하위목적의 내부·400m 시설 수 및 유형 다양성.
2. **상권 맥락 신호**: 기존 2025 PATH-v0 여가문화 점수. 최신 POI와 연도를 섞어 과거 예측 성능을 주장하지 않는다.
3. **접근성 신호**: 이미 계산한 08시·14시·19시 30분 접근성 등급.

가중치는 아직 확정하지 않는다. 각 담당자의 목적별 세부 분류를 모은 뒤, 동일한 정규화 방법·결측 처리·제외 기준을 적용해 확정한다.
