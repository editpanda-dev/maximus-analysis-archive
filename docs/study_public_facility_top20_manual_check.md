# 공부 체류 상권 Top 20 시설 수동 점검

원본 점검표는 `data/processed/study_public_facility_top20_manual_check.csv`다. 공부 체류 보조 순위의 상위 20개 상권에 연결된 공공 학습시설 후보를 지도 좌표와 원천 URL로 확인한 기록이다.

## 결과

- 검토 상권: 20개
- 상권-시설 연결: 117건
- 상권 폴리곤 내부: 18건
- 경계 400m 이내의 인접 후보: 99건
- 최대 확인 거리: 393.5m
- 지도 점검 상태: 모든 연결이 `PASS_VISUAL_INSIDE` 또는 `PASS_VISUAL_BUFFER400`
- 공개 접근 확인: 112건은 `VERIFIED`, 5건은 추가 확인이 필요한 `FOLLOWUP_REQUIRED`

각 행에는 상권 순위, 시설명·유형·좌표, 내부/인접 관계, 거리, 공개 접근 확인값, 원천 URL, 지도 URL, 예외 사유를 남긴다. `public_feature_included=1`인 시설만 현재 공공시설 점수에 반영된다.

## 한계

이 점검은 좌표와 공개된 원천 기록에 대한 수동 검토다. 실제 좌석 여유, 휴관, 회원·학생 전용 여부는 시시각각 달라질 수 있으므로 사용자 노출 전에는 시설 공식 페이지 또는 운영처에서 다시 확인해야 한다.
