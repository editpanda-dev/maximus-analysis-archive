# B078 1단계 진행 결과

## 결론

B078 전체 원본은 서울시 빅데이터캠퍼스 이용신청 후 캠퍼스 분석환경에서 열람하는 제한 데이터다. 현재 작업공간에는 2024년 3월 499행 샘플만 있으므로 목적별 이동량을 13개 괴리 후보와 통계적으로 결합할 수 없다. 대신 전체 원본을 받았을 때 즉시 실행할 수 있는 격자→행정동 변환 및 OD 집계 파이프라인을 완성했다.

공식 설명서에 따르면 B078의 좌표는 EPSG:5179이며, `MOVE_TIME` 단위는 분이다. 목적코드는 1 출근, 2 등교, 3 귀가, 4 쇼핑, 5 관광, 6 병원, 7 기타다. 기존 샘플 EDA에서 이동시간을 초로 간주해 60으로 나눈 계산은 정정했다.

## 샘플 실행 결과

샘플 499행에서 출발·도착에 등장한 고유 격자는 939개였다. 이 중 345개가 서울 행정동에 매칭됐다. 수도권 전체 표본을 서울 경계에 매칭했으므로 36.7%라는 수치 자체는 오류율이 아니다. 출발지와 도착지가 모두 서울에 매칭된 행은 156개다.

동대문구 출발행은 5개뿐이며 공식 분 단위 기준으로 30분 이내 이동은 장안1동→답십리2동 귀가 목적 1개뿐이다. 이 결과는 샘플 커버리지가 너무 작아 후보지 수나 목적 분포의 추정치로 사용하지 않는다.

## 생성 산출물

- `b078_cell_admin_dong_crosswalk.csv`: 250m 격자와 행정동 연결표
- `b078_mapped_rows.csv`: 원본 행에 출발·도착 행정동을 붙인 자료
- `b078_dong_od_mart.csv`: 날짜·시간·출발동·도착동·목적별 이동 집계
- `dongdaemun_origin_within_30min.csv`: 동대문구 출발 30분 이내 이동
- `dongdaemun_30min_destination_purpose.csv`: 목적지·목적별 집계
- `b078_mapping_audit.json`: 매칭률과 단위·경계 기준 감사 결과

## 전체 원본 적용 방법

빅데이터캠퍼스 분석환경에 `PURPOSE_250M_YYYYMM.csv`와 분석 시점에 맞는 행정동 경계를 준비한다. 다음 명령에서 입력 경로만 전체 원본으로 바꾼다.

```bash
python3 -m scripts.build_b078_dong_mart \
  --input /path/to/PURPOSE_250M_YYYYMM.csv \
  --boundary /path/to/period_matched_admin_dongs.geojson \
  --output data/processed/b078_dong_mart_YYYYMM \
  --max-minutes 30
```

현재 스크립트는 샘플 기준 기능 검증판이다. 월 전체 파일이 메모리를 초과하면 다음 개정에서 청크 처리로 전환한다. 반출 시에는 원본 250m 격자행을 내보내지 않고 행정동 이상으로 집계한 OD 마트와 매칭 품질표만 심사 대상으로 제출한다.
