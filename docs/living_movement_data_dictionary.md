# 생활이동 목적지 유입 피처

## 원천

- 제공기관: 서울특별시 열린데이터광장
- 데이터셋: 수도권 생활이동 (성 연령별, 도착지 기준)-내국인
- 사용 스냅샷: 2026-08 일별 파일 31개
- 다운로드 URL: https://data.seoul.go.kr/dataList/OA-22298/F/1/datasetView.do
- 라이선스: 공공누리 제1유형(출처표시)

원천의 한 행은 `도착 행정동 × 시간 코드 × 이동목적 × 성·연령 집계 이동인구`다. 개인의 이동기록이 아니며, 원천 대용량 파일은 저장소에 커밋하지 않는다.

## 목적 코드

| 원천 코드 | 피처 값 | 의미 |
|---:|---|---|
| 1 | commute | 출근 |
| 2 | school | 등교 |
| 3 | return_home | 귀가 |
| 4 | shopping | 쇼핑 |
| 5 | tourism | 관광 |
| 6 | hospital | 병원 |
| 7 | other | 기타 |

식사·카페·공부는 이 원천에서 직접 관측하지 않는다. 따라서 이 파일은 추천 정답값이 아니라 상권의 집계 목적지 유입 성격을 설명하는 보조 피처다.

## 공간·시간 결합

도착 행정동 코드를 `commercial_area_dong_overlap.csv`의 행정동 코드와 연결한다. 한 행정동 안에 여러 후보 상권이 있으면, 그 행정동에서 후보 상권이 차지하는 상대 중첩비율이 합계 1이 되도록 정규화해 이동량을 배분한다. 따라서 상권별 `inflow_count`는 실제 점포 방문자 수가 아니라, 행정동 목적지 유입을 상권 경계로 나눈 상대적 근사치다. 시간 코드는 오전(06–09시), 주간(10–16시), 저녁(17–21시), 야간(22–05시)으로 묶는다.

## 산출물 컬럼

| 컬럼 | 의미 |
|---|---|
| area_code | 공식 상권 코드 |
| time_slot | morning, daytime, evening, night |
| purpose | 7개 집계 이동목적 |
| inflow_count | 면적 중첩비율로 배분한 목적지 유입 추정량 |
| time_slot_inflow_total | 상권·시간대 전체 목적 유입량 |
| purpose_share | 상권·시간대 안에서 해당 목적이 차지하는 비중 |
| source_period | 원천 기준일 범위 |

`purpose_share`는 상권·시간대별 7개 목적의 합이 1이 되도록 검증한다. 행정동 내부에 여러 상권이 있을 수 있으므로, 배분값은 실제 점포 방문자 수가 아니라 상권 주변의 집계 유입을 근사한 값이다.
