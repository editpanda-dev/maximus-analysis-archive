# 장한별 카페·공부 1~7단계 통합 결과

**후속 실행 갱신:** 이 문서의 4단계 `실측 0건`은 당시 입력 상태다. 같은 날 공개 OSM 원천과 팀 카카오 340건을 확보한 뒤 경로를 추가 계산했다. 실제 경로 커버리지·김건우님 식사 점수 결합·현재 제출 판정은 [10월 6일 산출 시도와 인계](hanbyeol_oct06_execution_20261003.md)를 우선 읽는다. 진입 연결과 S4 근거가 미완료라 최종 공부·3목적 점수는 여전히 NA다.

작성·재검토: 2026-10-03 · 분석 키: 서울시 공식 상권 `area_code` · 분석 원본: **786개 상권**. 이 결과는 공개 데이터 기반 **탐색 기준선**이며, 개인별 만족도나 과거 예측 성능을 검증한 추천모델이 아니다. 김건우님 식사·쇼핑 분류안(`meal_shopping_taxonomy_20260930.md`, 사용자 제공본)과 맞춰 공식 업종의 주 목적을 정리했다.

## 수치와 분류 기준

- **상권 786개** 모두 `area_code`가 고유하다. 제과점 점포 행은 581개 상권, 매출 공개 행은 228개 상권에 있고, 호프·간이주점은 각각 647개·463개 상권이다. 공개 원천 행에서 식사 감소량은 두 업종 합계, 카페·여가 증가량은 각 이관 업종과 일치한다. 이는 **점포·매출 입력량 검산**이며 새로운 식사·여가 점수는 아니다.
- 카페의 공식 점수 업종은 커피·음료 `CS100010`과 제과점 `CS100005`이다. 김건우님 자료의 빵·도넛·떡·한과·빙수는 소상공인 세부업종 기반 *후속 점포 후보 분류*다. 공식 제과점 업종 수에 별도로 더하지 않는다.
- 카페 점수 상태는 `complete` 224개, `supply_only` 232개, `insufficient` 330개다. `full_score`는 커피·제과 **두 매출이 모두 관측된 상권**에만 산출한다. 부분 공개나 비공개 매출을 0으로 바꾸지 않는다. 완전관측군과 공급 전용군은 동일한 확신도의 순위로 섞지 않는다.
- 2026년 9월의 공공 POI 원본 268건과 이전 `public_feature_included=1` 236건은 다르다. 236은 이전 집계 플래그의 건수이며 엄격히 공개·공부 가능으로 확인된 시설 수가 아니다. 기존 공부 순위는 `study_legacy_proxy_score`로만 표시한다.
- 관광특구 **6개**는 786행 분석표·지도에서 유지하고 추천 탐색 순위에서만 제외했다. 이로 인해 세부 상권까지 삭제하지 않는다.

## 점수 설계 재검토

1. **S3a/S3b:** 지역별 백분위 상관 0.491은 두 원천이 같은 가게를 가리키는 비율이 아니다. 종전 30%+15%를 S3a 45%로 바꾼 프록시안의 Top 10 유지율은 70%, `max(S3a,S3b)`안은 50%다. 둘 다 검증된 공부 v1 점수가 아니다.
2. **인접시설:** 이전 공공시설의 *직선거리*에서 내부만 / 내부+25% / 내부+50%의 Top 10은 25%안 대비 60% / 100% / 80% 공통이다. 따라서 0.25 가중치가 보행거리 환경에서도 안정적이라고 단정하지 않는다.
3. **상권 크기:** 카페 절대 점포 수·면적 밀도·서울 대비 특화도·잔차의 면적 순위상관은 각각 0.753 / 0.183 / 0.194 / −0.005다. 잔차를 실제 카페점수 공급 대안으로 결합해 같은 관측·추천가능 상권 178개를 비교하면 면적 상관이 기존 −0.155에서 **−0.227**로 더 음수가 되고 Top 10 공통률은 60%다. 잔차 방식을 최종안으로 채택하지 않았다. 기존 카페 밀도 분모의 0.02km² 하한도 가정이다.
4. **시점:** 서울시 점포·추정매출은 2025Q4, 카카오 장소는 2026-09-18, 공공시설·OSM 후보는 2026년 9월 스냅샷이다. 이 조합을 2025년 예측 성능이라고 주장하지 않는다.

## 10월 6일 최종본으로 가기 위한 순서

1. **보행망 입력·QA:** 보행 허용 경로, 폴리곤 경계 진입점, 시설 출입구를 연결한다. 내부는 0m, 외부는 실제 최단 경로로 판정하고 400/500/600m 및 직선거리 대비 상권별 변화를 계산한다.
2. **시설 근거 검토:** 후보 427건을 상권 접근 후보로 좁힌 후 실제 URL·짧은 인용·영업 상태·좌석·노트북/장시간/학습 허용·검토자·시점을 기록한다. 근거 없으면 `unknown`으로 유지한다. 엄격 공개 학습시설도 기존 236 플래그에서 다시 판정한다.
3. **점수 통합:** 김건우님 식사 정의와 제과점 이관을 같은 목적 매핑 버전으로 재생성하고, 보행·S4 검증 및 면적·인접 가중치 민감도를 반영해 카페·공부 점수를 재산출한다. 공부가 NA인 상권은 결합 점수를 만들지 않는다.
4. **최종 순위·QA:** 786행·중복·결측·점수 범위·Top 10 안정성·관광특구·업종 중복을 검사하고, 동일 모집단 백분위로 카페+공부 및 식사+카페+공부를 다시 정렬한다. 점포 Top-K는 상권 점수와 별도 시설 후보 검증 후 수행한다.

**현재 제출 가능 범위:** 카페의 관측군 기준선과 목적별 *탐색용* 설명·지도, 분류·결측·중복·크기 보정 감사. **미완료 범위:** 실제 보행거리, 검증된 C_stay/S4, 엄격 공부 v1 점수, 최종 다목적 Top 10. QA의 PASS는 생성된 초안의 일관성만 뜻하며 이 네 결과가 완성됐다는 뜻은 아니다.
