# 식사·쇼핑 점수 기준선 v1 — 산출 방법과 결과

작성: 김건우 · 2026-10-06 · 기준 분기 2025년 4분기 · 브랜치 `codex/gunwoo/food-shopping-subtypes`

분류 정의는 [식사·쇼핑 하위분류 설계안](food_shopping_taxonomy_draft.md), 점수 흐름은 [10/1 피드백](feedback/2026-10-01_data_feature_feedback_actions.md)의 **Purpose Score v2** 규칙을 따른다. 이 문서는 786개 상권 점수표의 입력 변수, 가중치, 정규화, 결측 처리와 결과를 정리한다.

## 1. 재현

```bash
python scripts/build_food_shopping_v1.py --sbiz-zip <소상공인시장진흥공단_상가(상권)정보_20260630.zip>
python -m pytest tests/test_build_food_shopping_v1.py -q
```

- 필요 패키지: pandas, geopandas, folium, matplotlib
- 소상공인 원본 ZIP(352.7MB)은 저장소에 넣지 않는다. 내려받는 곳: https://www.data.go.kr/data/15083033/fileData.do
- 출력 폴더: `data/processed/food_shopping_v1/` (파일 목록은 같은 폴더의 README)

## 2. 점수 단위

| 단위 | 구성 | 비고 |
|---|---|---|
| 식사 `food` | M1 한식, M2 중식, M3 일식, M4 양식·외국식, M5 간편식, M6 치킨 | 제과·디저트는 카페로, 호프·요리주점은 여가로 귀속해 제외 |
| 쇼핑 `shopping` | SH1 패션·뷰티, SH2 디지털·가전, SH3 홈·리빙, SH4 취미·문화 | SH5 장보기·생활은 대분류 점수에 넣지 않음 |
| 하위분류 11개 | M1–M6, SH1–SH5 | 각각 대분류와 같은 식으로 따로 계산 |

- 업종 코드(소상공인 소분류, 서울시 서비스 업종)는 하위분류 하나에만 귀속한다. QA에서 중복 0건, 다른 목적 업종 혼입 0건을 확인했다.
- 서적·문구, 철물, 반려동물, 의료기기, 중고상품은 v1에서 **보류(제외)**한다.

## 3. 입력 변수

| 변수 | 원천·시점 | 정의 |
|---|---|---|
| 상권 안 밀도 | 소상공인 상가정보 2026-06-30 | 폴리곤 안 점포 수 ÷ (면적 km² + 0.05). 경계 위 점포 포함 |
| 도보권 밀도 | 같음 | 폴리곤 + **직선거리** 400m 버퍼 안 점포 수 ÷ 버퍼 면적 |
| 특화도(LQ) | 같음 | `((단위 점포 + 30×서울 비중) ÷ (전체 점포 + 30)) ÷ 서울 비중`, 도보권 기준 |
| 매출 생산성 지수 | 서울시 점포·추정매출 2025Q4 | 매출이 공개된 업종들의 실제 매출 ÷ (그 업종 점포 수 × 같은 업종 서울 점포당 매출 중앙값)의 합. 1이면 같은 업종 구성의 서울 평균 수준 |
| 매출 공개율 | 같음 | 매출이 공개된 업종의 점포 수 ÷ 단위 전체 점포 수 |
| 접근률 | 접근성 산출물 | `minimum_period_ratio`. 점수에는 넣지 않고 민감도와 설명문에만 사용 |

400m는 **보행경로가 아닌 직선거리**다(`walk_distance_basis=euclidean_400m_buffer`). 카페·여가 쪽은 카카오 보행경로로 재검증했으므로 조합 해석 시 이 차이를 함께 적는다.

매출 신호를 단순 점포당 매출이 아니라 업종 구성 보정 지수로 바꾼 이유는 [공격 점검](food_shopping_v1_redteam.md) A4에 있다. 분식·치킨 비중이 높은 상권은 같은 손님 수에도 점포당 매출이 낮게 나와 소비 점수가 업종 구성에 끌려갔다.

## 4. 정규화와 가중치

```text
P(x)    = 786개 상권 안에서의 평균순위 백분위 × 100. 점포가 0개면 해당 밀도 백분위는 0
공급 U  = 0.4 × P(상권 안 밀도) + 0.3 × P(도보권 밀도) + 0.3 × P(특화도)
소비 V  = P(매출 생산성 지수)       ← 매출 상태가 observed·estimated인 상권 안에서만 계산
점수    = 0.7 × U + 0.3 × V         (score_basis = full)
        = U                         (score_basis = supply_only)
```

- 가중치 합은 공급 내부 1.0, 공급·소비 1.0이다.
- 조합 점수는 목적별 점수를 786개 안에서 다시 백분위로 바꾼 뒤 **동등 평균**한다. 조합 Top 목록에는 모든 목적이 백분위 50 이상인 상권만 올린다. 한 목적이 아주 강해서 다른 목적의 약함을 덮는 경우를 막기 위해서다. `weakest_purpose_pct`를 함께 출력한다.
- 최고 하위분류와 Top 3 하위분류는 하위분류 **공급점수**로 고른다. 하위분류는 매출 결측이 많아서, 매출이 있는 하위분류와 없는 하위분류의 점수를 그대로 비교하면 서로 다른 척도를 비교하게 된다.

## 5. 결측·특수 상권 처리

| 항목 | 규칙 | 786개 중 (식사 / 쇼핑) |
|---|---|---|
| `observed` | 매출 공개율 70% 이상 | 571 / 133 |
| `estimated` | 30% 이상 70% 미만 | 113 / 334 |
| `missing` | 30% 미만이거나 도매 판정 | 102 / 319 |

- **결측을 중립값 50으로 채우지 않는다.** `missing`이면 공급점수만 쓰고, 순위도 `supply_only` 목록으로 따로 정렬한다. 이전 산출물(`food_shopping_size_neutral`)의 50 채움과 50% 단일 기준은 이번에 폐기했다.
- **도매:** 점포 20개 이상이면서 점포당 매출이 같은 업종 서울 중앙값의 8배 이상인 곳을 자동 후보로 잡는다(14곳). 의류류는 전통시장 유형일 때만 후보가 된다. 최종 판정은 객단가·야간 매출 검토표로 수동 확정했다(`data/reference/food_shopping/food_shopping_wholesale_review_2025q4.csv`).
  - `wholesale_apparel` 2곳(team204, 동대문상가A동): 쇼핑·SH1 매출 신호를 비우고 쇼핑 추천에서 제외
  - `wholesale_food` 2곳(노량진, 중부시장): SH5 매출 신호를 비우고 SH5 추천에서 제외
  - `retail` 10곳: 청량리 청과물·수산·농수산물·종합시장, 경동시장 2곳, 동서·수유·인왕·종로신진시장. 객단가가 서울 중앙값의 0.7–2.4배인 소매형이라 그대로 둔다.
  - 설계안의 "객단가 3배" 문장은 검토표에서 **도매 중심으로 판정하는 기준**이다. 자동 후보 기준이 아니다(그대로 자동 적용하면 123곳이 걸림).
- **관광특구:** 786행은 그대로 둔다. 기본 정책은 시나리오 C로, 관광특구 폴리곤 6곳만 추천에서 제외하고 그 안의 세부 상권 34곳은 유지한다. A(모두 포함)·B(내부 상권까지 제외)는 민감도 표로 비교한다.
- **소규모 상권:** 2025Q4 공식 점포 50개 미만인 107곳(`small_area`)은 점수는 그대로 두되 모든 Top 목록에서 뺀다. 빼기 전에는 매출 결측 Top 10의 8곳이 이런 상권이었다.
- **겹침:** Top 목록에서는 더 작은 폴리곤 면적의 30% 이상이 겹치는 상권 중 순위가 낮은 쪽을 뺀다.
- **표시 플래그:** `wide_area` 27곳(긴 변 1km 초과). 점수는 바꾸지 않는다.
- **하위분류 Top과 최고 하위분류:** 점포가 드문 하위분류는 1–2개만 있어도 백분위가 크게 오른다. 그래서 상권 안 점포 5개 이상인 하위분류만 후보로 본다. 이 조건을 넘는 하위분류가 없는 79곳은 최고 하위분류가 비어 있다.

- 탐색: 방이동먹자골목, 남영동 먹자골목, 인사동(식사), 명동역, 성수대교남단, 용산전자상가, 테크노마트, 잠실역, 학동사거리, 이태원시장, 수유역

- A(모두 포함): 식사+쇼핑 Top 10에 명동 관광특구가 들어오고, 그 안의 명동거리는 겹침 규칙으로 빠진다.
- B(내부 상권까지 제외): 식사 Top 10은 7개 유지(서울시청·을지로입구역·방이동먹자골목 이탈), 쇼핑은 8개 유지(종로신진시장·명동거리 이탈), 식사+쇼핑은 6개 유지(명동거리·이태원·잠실역·이태원시장 이탈). 도심 핵심 상권 상당수가 관광특구 안에 있어서, B를 기본으로 쓰면 도심 추천이 크게 줄어든다.

## 8. 한계와 남은 결정

- 점포 공급은 2026년 6월, 매출은 2025년 4분기 자료다. 상권 구조는 순위상관 0.987로 같지만, **2025년 매출 예측의 검증 입력으로는 쓰지 않는다**(`historical_2025_use_allowed=False`).
- 매출은 카드 추정매출이고 업종 칸이 비공개인 경우가 많다. 하위분류 단위에서는 `missing`이 많다(M2–M4, M6, SH2–SH4는 70% 이상). 그래서 하위분류 점수는 공급 중심으로 해석한다.
- 쇼핑 Top 10의 **방산시장(포장·제과 재료)과 대림상가(전자부품)**는 업체 거래 비중이 큰 전문시장일 수 있다. 쇼핑 매출의 10·20대 비중으로도 갈리지 않아(방산 4.3%, 종로신진 4.4%) 데이터 규칙으로는 분리하지 못했다. 팀 검토 대상이다.
- SH2 1위 남정초등학교처럼 아주 작은 폴리곤(0.018km²)에 같은 업종 점포가 몰린 곳은 하위분류 점수가 높게 나온다. 점포 5개 이상, 소규모 상권 제외 조건은 통과했지만 '목적지'로 보기는 약하다.
- 가중치는 학습된 최적값이 아니라 설명 가능한 기준선이다. 다음 주 생활이동 라벨 모델과 비교한다.
- 가격대(점심 객단가 저·중·고)는 설계안의 필터 속성이고, v1 점수표에는 아직 넣지 않았다.
